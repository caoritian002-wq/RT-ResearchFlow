# AlphaEar 金融报告框架

## 概述

本框架提供结构化金融报告的分析思路参考，包含信号聚类、章节撰写和报告组装三个分析维度。

## 分析思路

### 1. 信号聚类

将分散的金融信号归纳为 3-5 个核心逻辑主题，例如：供应链重构、政策收紧、行业景气度变化等。按主题关联性分组，为后续深度分析奠定结构基础。

### 2. 深度分析

对每个核心主题进行深入分析：
- 从宏观/行业背景出发，阐述传导机制
- 引用置信度和强度评分支撑观点
- 对受影响个股给出方向性预测
- 在关键传导环节使用 Mermaid 流程图展示逻辑链
- 使用 Markdown 表格展示数据对比

### 3. 报告组装

将各章节整合为完整报告，确保：
- H2/H3 层级结构清晰
- 包含执行摘要、风险因素、参考文献
- 输出严格使用 Markdown 格式
