# 产业链研究

## 目标

把一个陌生产业拆解成可计算、可比较、可更新、可证伪的知识体系，最终回答六个问题：

1. 产品如何从资源和原材料变成终端价值？
2. 产业链的利润、定价权和风险分别集中在哪里？
3. 当前真正的供给瓶颈是什么，瓶颈能持续多久？
4. 哪些国家、环节和公司具备可验证的竞争优势？
5. 哪些A股公司能够把产业变化转化为收入、利润和现金流？
6. 当前股价已经计入多少预期，现在介入是否具有合理的收益风险比？

本 Skill 默认先研究产业，不从股票涨跌或单家公司叙事出发。研究目的涉及投资时，必须继续完成“产业事实 → A股候选池 → 公司暴露度 → 财务弹性 → 财报验证 → 股价与市场预期 → 情景估值 → 投资决策”的闭环。股价只用于判断预期是否已经计入，不得用于反推产业逻辑是否成立。

## 适用场景

- 从零研究一个产业或细分产品
- 梳理上游、中游、下游和终端应用
- 分析原材料、加工工艺、设备、耗材和检测认证
- 判断涨价如何传导以及哪个环节真正受益
- 识别资源、设备、工艺、良率、认证或物流瓶颈
- 比较各国在资源、技术、制造、品牌和终端市场的生态位
- 查找全球或中国代表公司及市占率
- 验证某个行业景气、扩产、国产替代或供需短缺叙事
- 筛选真正受益的A股公司并比较业务纯度和利润弹性
- 结合季报、中报、年报、公告和股价判断产业变化是否已被定价
- 判断当前价格对应的隐含假设、安全边际和证伪条件
- 建立季度或月度产业跟踪面板
- 生成产业链思维导图和可供交互式UI使用的结构化图谱

## 基本原则

### 1. 先研究产品，再研究公司

先确定产品规格、物理形态、生产过程、客户和替代品，再把公司放入产业链。不得用一家公司的业务分类代替完整产业链。

### 2. 同时绘制五张地图

| 地图 | 核心问题 |
| --- | --- |
| 实物流 | 原料经过哪些工序成为中间品和最终产品？ |
| 设备流 | 每道工序依赖哪些设备、软件、耗材和检测工具？ |
| 资金流 | 收入、成本、资本开支和利润留在哪些环节？ |
| 信息流 | 谁定义规格、控制认证、决定订单和采购价格？ |
| 全球流 | 资源、技术、产能、品牌和终端需求掌握在哪些国家？ |

### 3. 严格区分事实、估算与假设

- **事实**：有公司公告、政府、协会、海关或其他原始资料支持。
- **估算**：注明公式、输入值、统计口径和误差来源。
- **假设**：说明成立条件，并给出能够推翻它的数据。

不得把产能当产量、报价当成交价、出货量当终端需求、行业受益当公司受益、收入市占率当产量市占率。

### 4. 统一时间和统计口径

所有关键数据标注日期、地区、产品规格、单位和统计范围。市占率必须同时写明分子、分母、年份、区域以及按收入、销量、产量、装机量还是产能计算。

### 5. 结论必须可以证伪

每项核心结论至少给出一个验证指标和一个失效条件。没有失效条件的观点只是叙事，不是研究结论。

## 启动研究

开始前明确以下输入。用户未提供时，根据上下文做保守假设；只有歧义会显著改变结论时才提问。

| 输入 | 需要明确的内容 |
| --- | --- |
| 研究对象 | 产业、细分产品、具体规格或技术路线 |
| 地理范围 | 全球、中国、某个国家或区域 |
| 时间范围 | 当前景气、未来1至3年、长期技术演进 |
| 研究目的 | 学习、竞争分析、战略决策或投资研究 |
| 输出深度 | 快速扫描、标准研究或深度研究 |
| 估值基准日 | 投资研究使用哪个交易日的收盘数据 |
| 投资期限 | 交易、6至12个月或1至3年 |
| 比较基准 | 沪深300、中证全指或匹配的行业指数 |
| 安全边际 | 用户要求的最低预期收益或最大可承受回撤 |

研究对象必须尽量具体。例如不要只研究某种大类材料、设备或消费品，应进一步区分产品代际、规格、性能等级和应用场景。用户未指定投资参数时，默认采用最新可得交易日、6至12个月观察期、沪深300与匹配行业指数双基准；安全边际不替用户预设，只报告不同情景的预期收益和下行风险。

## 标准流程

### 研究资源配置与停止规则

研究深度不按章节平均分配，而由三个因素共同决定：结论敏感度、证据不确定性和变化速度。只做高、中、低判断，不构造缺少统一口径的精确评分。

| 研究档位 | 适用条件 | 执行动作 |
| --- | --- | --- |
| 快速通过 | 对核心结论低敏感、格局稳定、变化慢且可靠资料充足 | 引用高质量第三方或原始数据完成口径核验，不自建复杂模型 |
| 标准验证 | 存在重要不确定因素，但单项变化不足以颠覆利润池或投资结论 | 完成必要的交叉验证和情景分析 |
| 深度研究 | 位于瓶颈、利润迁移节点，或一项证据足以改变估值和投资动作 | 集中使用供需、工艺、共享要素、政策、公司和财务工具 |

每进入一个扩展模块前先回答：“该分析结果是否可能改变核心假设状态、情景权重、合理价值或投资动作？”若不能，标记为背景信息并停止扩展。继续收集证据已不能显著改变上述四项时，达到本轮研究停止条件；记录数据缺口和下一触发指标，而不是为填满框架继续搜索。

### 执行机制：假设、反证与修正闭环

十三步是研究框架，不是只能顺序执行的流水线。研究开始时先提出1至2个最关键、可证伪的初始假设，并优先寻找成本最低、区分度最高的反证。新证据改变结论时，立即回到相关步骤修正产业链、利润池和公司映射，不等到报告末尾才处理冲突。

建立假设台账：

| 核心假设 | 初始依据 | 最便宜的反证 | 当前状态 | 受影响结论 | 下一步验证 |
| --- | --- | --- | --- | --- | --- |
| 瓶颈位于某环节 | 价格、交期、集中度 | 库存、利用率、头部公司毛利率 | 待验证 | 供需、利润池 |  |
| 利润流向某环节 | 售价、成本和竞争格局 | 平均售价、现金流或毛利率未改善 | 待验证 | 公司映射、估值 |  |

假设状态统一使用“待验证、获得支持、被削弱、已推翻”。至少设置三个强制回访点：

1. 第三步后：工艺、设备、良率和认证是否支持最初的瓶颈假设。
2. 第五步后：供需、库存、交期和价格是否支持短缺与利润迁移假设。
3. 第十一步后：财报、订单和市场定价是否支持利润兑现及预期差假设。

快速查看代表公司的财报可以用于反证，但不得让单家公司重新定义产业边界。假设被推翻时，保留修正记录和触发证据，避免只展示最终结论而隐藏研究路径。

### 第一步：界定边界并建立产品树

回答：

- 最终交付的产品或服务是什么？
- 产品按规格、材料、性能、技术路线和应用如何分类？
- 替代品、互补品和上一代产品是什么？
- 主流与替代技术分别处于实验室、中试、认证还是规模量产阶段？
- 产业链从哪里开始，到哪个最终付费者结束？
- 哪些相邻业务不属于本次研究范围？

输出产品树：

```text
产业
├─ 产品大类A
│  ├─ 标准品
│  ├─ 高端品
│  └─ 特种品
├─ 产品大类B
├─ 替代产品
└─ 下游应用
```

检查点：不同产品规格如果对应不同原料、设备、客户、价格或竞争格局，必须分开研究。

对存在路线争议或颠覆风险的产业，建立技术路标：

| 技术路线 | 当前阶段 | 量产平均良率 | 单位成本 | 成本下降斜率 | 配套成熟度 | 头部客户导入 | 资本兼容性 | 下一里程碑 |
| --- | --- | ---: | ---: | ---: | --- | --- | --- | --- |
| 主流路线 |  |  |  |  |  |  |  |  |
| 替代路线 |  |  |  |  |  |  |  |  |

技术阶段统一为“实验室验证 → 工程样品 → 中试线 → 头部客户认证 → 小批量商业订单 → 重复订单 → 规模量产 → 成本或性能超越主流路线”。不得用实验室最高指标替代量产平均良率，也不得把客户测试或送样写成商业导入。

### 第二步：绘制实物产业链

按照“输入物 → 工序 → 中间品 → 工序 → 最终产品 → 最终付费者”展开，不要停在上市公司的直接客户。

| 环节 | 输入物 | 核心工序 | 输出物 | 单耗 | 良率/损耗 | 直接客户 | 最终用途 |
| --- | --- | --- | --- | ---: | ---: | --- | --- |
| 上游 |  |  |  |  |  |  |  |
| 中游 |  |  |  |  |  |  |  |
| 下游 |  |  |  |  |  |  |  |

逐环节追问：

- 单位产品需要多少原料和能源？
- 是否产生副产品，废料能否回收？
- 名义产能如何换算成有效产量？
- 良率、开工率和产品结构如何影响实际供给？
- 不同规格、性能等级和认证状态对应多少有效供给，低端产能能否切换为高端产能？
- 扩产、爬坡和客户认证分别需要多久？
- 运输半径、保质期、仓储或危险品要求是否限制供给？

总量不足以判断过剩或短缺时，按“产品规格 × 产线兼容性 × 良率 × 认证状态”拆分有效供给。低规格产能不能在合理时间和成本内切换时，不得用于抵消高规格缺口；高规格产能闲置也不等于对应下游需求充足。

### 第三步：拆解工艺、设备和支撑层

为每道关键工序建立设备表：

| 工序 | 核心设备/软件 | 关键参数 | 供应商 | 国产化率 | 交付周期 | 寿命 | 耗材/服务 | 替代难度 |
| --- | --- | --- | --- | ---: | ---: | ---: | --- | --- |
|  |  |  |  |  |  |  |  |  |

区分四种生产能力：

1. 买到通用设备即可生产。
2. 设备可以买到，但配方和工艺窗口难以掌握。
3. 设备和工艺已掌握，但高良率、一致性和稳定量产依赖长期经验。
4. 能够生产仍不够，还必须通过客户认证、专利授权或监管许可。

同时补充软件、工业设计、检测仪器、认证机构、维护服务和关键耗材。支撑层可能比制造环节更稀缺。

### 第四步：建立单位经济模型和利润池

拆解每个环节的收入、成本和资本效率：

$$
\text{利润}=\text{销量}\times(\text{售价}-\text{单位变动成本})-\text{固定成本}
$$

$$
\text{有效产量}=\text{名义产能}\times\text{开工率}\times\text{良率}
$$

至少收集：

- 市场规模、销量、产能和有效产量
- 产能利用率、库存和在建产能
- 产品售价及不同规格价差
- 原料、能源、人工、折旧和费用结构
- 毛利率、净利率、ROIC和自由现金流
- 单位资本开支、扩产周期和爬坡周期

绘制产业利润池时，不仅比较毛利率，还应比较利润总额和资本回报。高毛利的小市场不一定比低毛利的大市场更有价值。

### 第五步：分析供需和价格传导

先识别价格形成机制：

- 交易所或公开市场定价
- 现货报价、拍卖或招标
- 长协价、年度框架价或季度议价
- 成本加成
- 原材料联动公式
- 品牌定价、渠道定价或监管定价

建立价格传导表：

| 环节 | 价格指标 | 报价/成交 | 调价频率 | 合同期限 | 向下游传导时滞 | 成本转嫁率 | 库存影响 |
| --- | --- | --- | --- | --- | ---: | ---: | --- |
|  |  |  |  |  |  |  |  |

区分四类涨价：

| 涨价类型 | 主要原因 | 对利润的一般含义 |
| --- | --- | --- |
| 主动涨价 | 需求旺盛、供给稀缺、议价权增强 | 通常提升利润率 |
| 成本推动 | 原料、能源或人工上涨 | 取决于转嫁速度和幅度 |
| 库存推动 | 补库存、囤货或渠道挤兑 | 持续性较弱，可能反转 |
| 结构性涨价 | 高端产品占比提升 | 需验证销量结构和单位盈利 |

价格上涨不等于利润上涨。使用以下桥接关系：

$$
\Delta\text{利润}\approx\text{销量效应}+\text{售价效应}-\text{原料效应}-\text{费用效应}
$$

检查价格传导时，至少比较现货价、真实成交价、公司平均售价、毛利率和库存变化，避免只用B2B挂牌价下结论。

#### 价格方向、涨价斜率与持续条件

价格继续上涨、涨价斜率维持和企业利润继续增长是三个不同命题。除价格方向外，必须比较变化速度和边际驱动：

$$
	ext{价格方向}=\Delta P
$$

$$
	ext{涨价斜率}=\frac{\Delta P}{\Delta t}
$$

$$
	ext{斜率变化}=\frac{\Delta^2P}{\Delta t^2}
$$

至少使用两个以上可比时间窗口，按统一规格、地区、税率、合同和交付口径比较现货、长协、招标、公司平均售价与价差。若缺少连续成交序列，只能判断价格方向或高位状态，不得声称原有涨价斜率仍在维持。

| 时间窗口 | 价格方向 | 斜率状态 | 边际驱动 | 继续上涨的必要条件 | 首个证伪指标 |
| --- | --- | --- | --- | --- | --- |
| 未来1季度 | 上涨/高位震荡/回落 | 加速/放缓/转负/未知 |  |  |  |
| 未来半年 |  |  |  |  |  |
| 未来1年 |  |  |  |  |  |

必须区分企业盈利对“继续涨价”“维持高价”和“长协补涨”的敏感度。价格斜率放缓不必然导致利润下降，但若当前股价隐含价格持续加速，则高位横盘也可能构成估值不及预期。

#### 下游承受能力与需求破坏

成本可以传导不等于下游愿意无限接受涨价。按最终客户和应用测算目标产品占客户BOM、项目总成本或总拥有成本的比例，并调查延期采购、减少用量、降规格、替代材料、二供导入、重新招标、合同取消和延长付款等抵触行为。

$$
	ext{涨价对客户总成本的影响}
=\text{产品涨幅}\times\text{产品成本占比}
$$

| 下游客户/应用 | 产品成本占比 | 当前涨价影响 | 替代与降规格难度 | 已出现的抵触行为 | 需求破坏阈值 | 观察指标 |
| --- | ---: | ---: | --- | --- | ---: | --- |
|  |  |  |  |  |  |  |

需求破坏阈值优先来自历史订单弹性、招标量价、客户预算、替代方案和订单取消，不凭主观填写。无法量化时给出方向性区间和触发行为。涨价后销量、订单覆盖期或终端开工下降时，必须区分正常季节性、主动去库存与真实需求破坏。

#### 扩产博弈与合成谬误

景气上行时，单家公司扩产可能合理，但所有玩家同时扩产会形成集体过剩。汇总主要玩家的宣布、在建和已投产能力，不得只分析单一企业计划。

| 公司/主体 | 产品规格/等级 | 宣布产能 | 在建产能 | 产线兼容与切换成本 | 客户认证状态 | 预计投产 | 投产概率 | 稳态利用率 | 稳态良率 | 概率加权有效产能 |
| --- | --- | ---: | ---: | --- | --- | --- | ---: | ---: | ---: | ---: |
|  |  |  |  |  |  |  |  |  |  |  |

对足以改变供需和价格的项目建立有效产能释放时钟，不以宣布投产日替代可销售产品形成时间：

| 公司/项目 | 产品规格 | 宣布/开工 | 设备到位 | 点火/试产 | 良率爬坡 | 客户认证 | 有效供给形成 | 基准期新增有效产量 | 延迟与失败条件 |
| --- | --- | --- | --- | --- | --- | --- | --- | ---: | --- |
|  |  |  |  |  |  |  |  |  |  |

最终必须回答：在需求情景不变时，新增有效供给最早在哪个季度足以改变利用率、交期、库存或价格；若无法确定，明确下一项可观察里程碑，而不是只引用笼统扩产周期。

$$
{\text{概率加权新增供给}}
=\sum_i\text{规划产能}_i\times\text{投产概率}_i\times\text{利用率}_i\times\text{良率}_i
$$

按产品规格分别将概率加权新增供给与未来三年的悲观、基准和乐观需求比较，再汇总总量。进一步调查融资成本、二级市场估值奖励、地方招商与补贴、战略卡位、停产成本和退出壁垒，判断扩产是否会在经济回报下降后继续。若总量过剩但高规格有效供给短缺，应标记为结构性错配，不得直接得出全行业过剩结论。

价格战持续时间需要比较主要玩家的现金及可交易资产、经营现金流、未使用授信、净负债、利息负担、维持性资本开支、扩张性资本开支、控股股东支持和再融资能力。行业亏损不代表供给会立即退出，现金消耗能力决定出清速度。

#### 跨行业溢出与共享要素竞争

产业可能与其他行业争夺同一种原材料、设备、能源、土地、物流、人才或融资。只有当外部行业需求存在可验证的定量或方向性证据，并足以改变共享要素的价格、交期、分配或政策优先级时才展开本模块；仅存在一般业务联系不构成纳入理由。

| 共享要素 | 本产业需求 | 竞争产业 | 竞争产业需求变化 | 总供给弹性 | 分配机制 | 价格/交期影响 | 优先获得者 |
| --- | ---: | --- | --- | --- | --- | --- | --- |
| 原材料 |  |  |  |  | 市场价/长协/行政配置 |  |  |
| 核心设备 |  |  |  |  | 排产/认证/预付款 |  |  |
| 能源与公用工程 |  |  |  |  | 电价/配额/限产 |  |  |
| 人才、土地与物流 |  |  |  |  | 薪酬/市场/政府配置 |  |  |
| 融资 |  |  |  |  | 信贷/债券/股权/补贴 |  |  |

$$
{\text{本产业可获得供给}}
=\text{共享要素总供给}-\sum_j\text{竞争产业需求}_j+\text{新增供给}
$$

至少回答：外部行业会不会把目标产业的成本曲线整体上移；瓶颈是否因多行业争夺而更刚性；设备和人才是否被其他行业挤占；资本是否从目标产业流出或流入；真正受益者是否是向多个行业供货的共享上游，而非目标产业本身。跨行业影响需要进入供需情景、利润池和公司映射，不能只作为背景描述。

执行删除测试：暂时移除该外部产业后，目标产业的供需、价格、交期、瓶颈、政策优先级或投资结论是否变化。若均不变化，该因素属于背景噪音，不进入模型、结构化图谱和监控面板；若变化，记录受影响结论、传导路径和可观察指标。

### 第六步：追到最终需求

把客户分为：

| 类型 | 决策因素 | 需求特点 |
| --- | --- | --- |
| To C | 品牌、价格、体验、渠道 | 分散、变化快、营销重要 |
| To B | 性能、可靠性、总拥有成本、认证 | 客户集中、合同较长 |
| To G | 预算、政策目标、招标和合规 | 周期长、价格透明、回款重要 |
| To B To C | 企业采购、消费者使用 | 两端需求共同决定 |

用可计算方式拆解终端需求：

$$
\text{需求量}=\text{终端数量}\times\text{单机用量}\times\text{渗透率}\times\text{更换频率}
$$

判断需求增长来自：

- 终端数量增加
- 单机价值量或单机用量提升
- 渗透率提高
- 产品升级和替换周期缩短
- 渠道补库存
- 政策补贴或一次性项目

必须区分终端消费、渠道出货和生产商排产。出货增长可能只是库存转移。

终端需求结论同时给出数量增长、价格敏感度和预算约束。若上游价格上涨但终端预算固定，应说明下游通过减少数量、压缩其他环节利润、延迟项目还是提高总预算来吸收成本；不得默认所有涨价都能无损传导。

### 第七步：识别并验证真正瓶颈

瓶颈可能来自资源、能源、设备、工艺、良率、人才、专利、标准、认证、产能、物流或地缘政治。

对候选瓶颈按1至5分评价：

| 维度 | 判断问题 |
| --- | --- |
| 必要性 | 缺少它是否会让整条产业链停摆？ |
| 集中度 | 供应是否集中在少数公司或国家？ |
| 扩产刚性 | 新增有效供给需要多久？ |
| 替代难度 | 是否有成熟替代品，切换成本多高？ |
| 良率/一致性 | 名义产能能否稳定转化为合格产品？ |
| 认证周期 | 新供应商进入客户体系需要多久？ |
| 定价能力 | 稀缺性能否转化为持续提价和利润？ |
| 持续时间 | 短缺是几个月、几年还是结构性的？ |

真正瓶颈通常同时具备：不可缺少、供应商少、扩产慢、替代困难、能够获得超额利润。

警惕伪瓶颈：价格虽然上涨，但技术门槛低、潜在产能大、扩产周期短或需求主要来自补库存。这通常是周期性错配，不是长期壁垒。

使用以下指标交叉验证，不设置跨行业统一阈值，而是比较该行业历史常态、同周期和同类产品：

| 指标 | 真瓶颈信号 | 伪瓶颈或投机信号 |
| --- | --- | --- |
| 显性库存 | 持续下降并处于历史低分位 | 价格上涨但库存仍高或继续累积 |
| 交付周期 | 显著超过历史正常水平并继续延长 | 交期未明显变化，短期仍可排产 |
| 订单能见度 | 覆盖期延长且终端需求可验证 | 订单主要来自渠道抢货或重复下单 |
| 产能预订率 | 远期有效产能被锁定 | 近期产能仍可灵活安排 |
| 合同质量 | 有预付款、不可取消、长期锁量 | 意向订单、可取消框架或授予上限 |
| 现货与长协 | 长协逐步跟涨，价差可解释 | 仅现货脉冲上涨，长协没有变化 |
| 企业盈利 | 平均售价、毛利率和现金流连续改善 | 涨价没有进入平均售价和利润 |
| 下游库存 | 正常或偏低，终端消耗同步上升 | 渠道库存和应收快速累积 |

若库存高企、交期未延长、长期合同未跟涨且公司盈利未改善，即使现货价格快速上涨，也不得认定为结构性瓶颈。数据不足时逐项标记未知，不合成看似精确的统一瓶颈指数。

验证瓶颈时必须检查同一资源或设备是否被其他产业争夺。若目标产业自身需求平稳，但外部产业需求足以占用新增供给，瓶颈仍可能成立；反之，忽略竞争产业供给退出或需求回落会高估瓶颈持续时间。

### 第八步：绘制全球生态位

不要只写“某国领先”，应按能力拆分：

| 国家/地区 | 资源 | 基础材料 | 核心设备 | 工艺/IP | 规模制造 | 品牌/渠道 | 标准制定 | 终端需求 | 主要依赖 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |  |  |

重点调查：

- 资源储量、产量和加工能力是否位于同一国家
- 核心原料、设备和零部件的进口依赖度
- 全球出口份额和主要贸易流向
- 关税、补贴、本地化要求和出口管制
- 能源、人工、融资、物流和合规成本
- 产业集群完整度和工程师供给
- 专利、标准、品牌、渠道和终端市场控制权
- 断供后替代来源、切换时间和损失规模

国家生态位是动态的。分别记录当前地位、在建能力、政策目标和实现目标所缺少的条件。

成本优势必须区分来源，不能只比较当期单位成本：

| 优势类型 | 常见来源 | 可复制性 | 政策敏感度 | 持续性判断 |
| --- | --- | --- | --- | --- |
| 结构性优势 | 产业集群、供应商网络、工程经验、良率、物流协同和客户共同开发 | 通常较低 | 通常较低 | 通过迁移成本、配套密度和学习曲线验证 |
| 条件性优势 | 能源、补贴、税收、汇率、环保标准和低价融资 | 通常较高 | 通常较高 | 通过政策、能源、合规和融资情景验证 |

同一主体可同时拥有两类优势。公司或国家卡片需写明优势来源、可复制性、政策敏感度和预计持续期；若成本领先主要依赖条件性优势，不得直接认定为长期护城河。

#### 条件式政策内生模块

当政府采购、补贴、牌照、价格管制、产业安全、环保约束或国有资本显著影响供需时，必须把政策视为产业参与者的决策变量，而不是一次性外部冲击；纯市场化且政策影响弱的产业可以标记为不适用。

| 政策主体 | 核心目标 | 可用工具 | 对供需和成本曲线的影响 | 冲突目标 | 财政与执行可持续性 | 关键窗口 |
| --- | --- | --- | --- | --- | --- | --- |
| 中央或国家层级 | 安全、物价、技术、就业、环保 | 采购、补贴、关税、监管、信贷 |  |  |  |  |
| 地方或区域层级 | 投资、就业、税收和产业集群 | 土地、融资、招商和配套 |  |  |  |  |

分析政策目标发生冲突时的优先级、执行主体的财政能力、政策退出成本和受益者行为反馈。规划初期、选举、预算、补贴退坡等时间窗口只能作为待验证假设，不得机械地当成固定周期规律。

政策资源需要在多个产业之间分配时，比较各产业对安全、就业、物价、税收、能源和技术自主目标的贡献，判断采购、信贷、土地、能源和补贴的实际优先顺序。不得假设目标产业天然拥有政策优先权。

### 第九步：锁定代表公司和市占率

每个关键环节寻找全球前三和目标地区前三，并建立统一公司卡片：

| 项目 | 内容 |
| --- | --- |
| 所处环节 | 资源、材料、设备、制造、集成或渠道 |
| 核心产品 | 规格、技术路线和应用 |
| 业务暴露度 | 相关收入、利润和资本开支占比 |
| 产能与产量 | 名义产能、有效产能、开工率和良率 |
| 客户结构 | 前五客户、认证状态和合同期限 |
| 市占率 | 区域、产品、年份和统计口径 |
| 成本优势 | 结构性/条件性来源、可复制性、政策敏感度和预计持续期 |
| 壁垒来源 | 资源、设备、工艺、专利、认证、品牌或渠道 |
| 扩产计划 | 规模、投产时间、爬坡和资金来源 |
| 主要风险 | 替代、降价、扩产、贸易限制和客户流失 |

市占率计算：

$$
\text{市占率}=\frac{\text{公司在统一口径下的销量或收入}}{\text{同一产品、地区和时期的市场总量}}
$$

行业集中度：

$$
CR_n=\sum_{i=1}^{n}\text{前}n\text{家公司市占率}
$$

不得混用全球与中国、收入与销量、产量与产能、全部产品与细分规格。缺少可靠数据时，应写“暂无统一口径”，并给出可复核的估算过程，不得制造精确数字。

### 第十步：判断受益环节并映射公司

行业景气不等于产业链所有环节受益。使用以下框架：

$$
\text{受益程度}\approx\text{业务暴露度}\times\text{利润弹性}\times\text{市占率}\times\text{持续时间}
$$

优先寻找：

- 相关业务收入和利润占比较高
- 有闲置有效产能，可迅速放量
- 成本稳定且具备主动提价能力
- 客户认证壁垒高、替代者少
- 扩产速度快于竞争对手
- 新增利润不会被其他亏损业务抵消
- 资本开支和现金流能够支撑扩产

涉及上市公司时，按以下顺序验证：

1. 产业变化是否真实存在。
2. 公司是否真正生产受益产品，而非只有概念关联。
3. 该产品占公司收入和利润的比例。
4. 价格、销量和成本变化能贡献多少增量利润。
5. 增量利润是否已被市场一致预期和估值反映。

### 第十一步：完成A股定价与投资验证

研究目的涉及投资时，本步骤为必选项；学习、政策或战略研究可以明确标记为不适用。候选池必须从前述产业链和受益映射中产生，不得先列概念股再倒推产业逻辑。

#### 11.1 建立A股候选池

每个关键受益环节优先选择业务可验证、财务可拆分的A股公司，并建立横向评分表：

| 维度 | 核验内容 | 常见误判 |
| --- | --- | --- |
| 业务纯度 | 目标产品占收入、毛利、资本开支和新增订单的比例 | 公司有产品但收入占比极低 |
| 利润弹性 | 价格、销量、利用率每变化一定幅度对利润的影响 | 把收入增长等同于利润增长 |
| 有效产能 | 可用产能、开工率、良率、产品切换和认证状态 | 把名义产能当成可销售产量 |
| 订单质量 | 客户、金额、期限、执行率、定价机制和回款条件 | 把框架协议上限当确认收入 |
| 财务质量 | 毛利率、ROIC、现金流、应收、存货、负债和资本开支 | 忽略回款和扩产消耗 |
| 治理风险 | 股权质押、减持、关联交易、商誉和资本配置纪律 | 只看产业位置，不看公司治理 |
| 估值状态 | 当前估值、历史分位、同业差异和周期位置 | 用单一PE比较不同商业模式 |
| 市场预期 | 股价、成交量和盈利预测是否提前反映产业变化 | 用涨跌幅直接替代预期分析 |

候选池应分为核心标的、观察标的和排除标的。排除理由同样保留，例如业务占比过低、利润不可拆分、治理风险高、估值隐含假设过强或缺少可验证数据。

#### 11.2 获取并统一股价口径

默认获取估值基准日前最新可得的当前价格，以及近6个月、1年和3年行情。至少计算：

- 区间收益率、最大回撤、年化波动率和成交额变化
- 相对沪深300与匹配行业指数的超额收益
- 产业价格、订单、业绩预告和定期报告公告日前后的事件窗口表现
- 股价上涨来自盈利上修还是估值扩张

统一数据规则：

- 当前价格和总市值使用基准日不复权收盘价。
- 区间收益和技术走势使用前复权价格，并注明复权方式。
- 分红、送转、配股、增发、拆并股和长期停牌必须调整或说明。
- 明确交易日期、数据源、时区和是否包含盘中数据。
- 不得使用基准日后才公开的信息解释基准日的投资合理性。
- 行情数据无法获得或来源不稳定时，明确标记缺口，不凭走势图目测编造精确收益率。

股价表现不是结论本身。必须与同期盈利预测、估值倍数和基本面催化变化配对解释。

#### 11.3 用财报验证产业传导

至少读取最近4个单季数据、最近一期中报、最近2至3年年报、最新业绩预告或快报，以及影响目标业务的订单、扩产、价格和客户公告。按公告日期建立时间轴，不按报告期结束日假设市场已经知情。

建立公司利润桥：

$$
\Delta\text{利润}
=\text{销量效应}+\text{售价效应}+\text{产品结构效应}
-\text{原料效应}-\text{折旧与费用效应}-\text{其他业务拖累}
$$

重点核验：

- 目标业务收入、销量、平均售价和毛利率是否同步改善
- 库存是否先于收入合理增加，还是形成跌价和减值风险
- 应收账款、合同资产和经营现金流是否支持利润质量
- 在建工程和资本开支何时转化为新增有效供给与折旧
- 利润增长来自主业，还是补贴、投资收益、处置和汇兑
- 管理层指引与后续实际结果是否持续一致

业务分部披露不足时，给出可复核区间或标记“无法拆分”，不得把集团利润全部归因于目标产业。

对处于繁荣、过热或利润快速释放阶段的公司，必须执行峰值利润与正常化利润检验，区分结构升级形成的新中枢和供需错配形成的周期超额利润：

| 指标 | 当前值 | 历史中枢 | 历史峰值 | 同业水平 | 可持续部分 | 周期性部分 | 回落触发条件 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 毛利率 |  |  |  |  |  |  |  |
| 净利率 |  |  |  |  |  |  |  |
| 单位毛利 |  |  |  |  |  |  |  |
| ROIC |  |  |  |  |  |  |  |

$$
	ext{增量利润率}=\frac{\Delta\text{利润}}{\Delta\text{收入}}
$$

使用历史同周期、同业和单位经济解释利润率上升。若利润率已超过历史峰值或增量利润率显著高于稳态水平，估值必须同时采用峰值利润和正常化利润，不得将最新单季利润机械年化为永久盈利能力。

#### 11.4 判断产业变化是否已被定价并识别预期差

先对比三类信息，不把管理层表达、卖方观点和股价走势当作产业事实：

| 层次 | 核心问题 | 主要证据 |
| --- | --- | --- |
| 产业事实 | 价格、库存、交期、有效产能和利润池实际发生了什么 | 原始供需数据、上下游交叉验证和公司实际经营结果 |
| 公司叙事 | 管理层、公告和卖方一致预期声称将发生什么 | 定期报告、业绩会、公告、盈利预测及其历史兑现率 |
| 市场定价 | 当前股价隐含了什么销量、售价、利润率、持续期和估值倍数 | 反向估值、盈利预测变化、估值分位和事件窗口表现 |

将股价、盈利预期和估值变化放入同一矩阵：

| 市场表现 | 财务验证 | 一般解释 |
| --- | --- | --- |
| 股价上涨，盈利预测同步上修，估值稳定 | 订单、售价、毛利率和现金流改善 | 基本面驱动，需判断盈利上修是否仍有空间 |
| 股价上涨快于盈利上修，估值显著扩张 | 财报尚未充分验证 | 预期可能提前计入，关注催化兑现风险 |
| 股价滞涨或下跌 | 订单、售价和利润已经改善 | 可能存在预期差，也可能有治理或持续性风险 |
| 股价上涨 | 平均售价、毛利率和现金流未改善 | 主题交易特征较强，不能确认产业利润兑现 |

禁止仅凭股价近半年上涨或下跌判断“已经反映”或“尚未反映”。需要回答：市场当前隐含的销量、售价、利润率、增长期限和估值倍数分别是什么。

在业绩预告、快报、定期报告或重大订单发布前，保存可获得的一致预期快照，避免使用公告后的上调预测解释公告前定价。至少记录营收、归母净利润、扣非净利润、EPS、毛利率和现金流中实际可得的项目：

| 预测指标 | 样本数 | 均值 | 中位数 | 最低值 | 最高值 | 数据截止日 | 预测分歧来源 |
| --- | ---: | ---: | ---: | ---: | ---: | --- | --- |
| 营业收入 |  |  |  |  |  |  |  |
| 归母净利润 |  |  |  |  |  |  |  |
| 扣非净利润 |  |  |  |  |  |  |  |
| 毛利率/现金流 |  |  |  |  |  |  |  |

一致预期必须注明统计平台、样本时间窗和机构数量；均值可能受极端预测影响，存在明显分歧时同时报告中位数和预测区间。单一研报只能代表该机构模型，不能称为市场一致预期。

建立预期阶梯，将公司实际结果分别与低位预测、一致预期中枢、乐观预测和当前股价隐含预测比较：

| 预期层次 | 营收 | 归母/扣非利润 | 利润率 | 当前完成度 | 后续所需增量 | 结论 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 机构低位预测 |  |  |  |  |  |  |
| 一致预期中枢 |  |  |  |  |  |  |
| 乐观机构预测 |  |  |  |  |  |  |
| 当前价格隐含预测 |  |  |  |  |  |  |
| 公司实际结果 |  |  |  |  |  |  |

业绩评价至少区分“超过自身情景”“超过低位机构预测”“超过一致预期”和“超过股价隐含预期”。公告未披露营收、毛利率或现金流时，对应项目必须标记待验证，不得因利润超预期推定其他指标同步达标。

三者存在偏差不等于存在可交易的预期差。只有事实证据能够支持差异、市场隐含假设可以反推、存在可观察催化剂或验证窗口、估值提供合理收益风险比，并且证伪条件与预期差衰减期限明确时，才将其列为投资机会或风险。否则只记录为待验证分歧，不纳入目标价和投资动作。

| 产业事实与叙事差异 | 市场定价状态 | 可能含义 | 验证窗口/催化剂 | 衰减期限 | 投资动作 |
| --- | --- | --- | --- | --- | --- |
| 事实强于叙事 | 尚未反映 | 潜在上行预期差 |  |  |  |
| 事实弱于叙事 | 仍按乐观假设定价 | 潜在下行风险 |  |  |  |
| 事实与叙事一致 | 已大部分反映 | 赔率可能不足 |  |  |  |

#### 11.5 建立情景估值和投资决策

至少设置悲观、基准和乐观三种情景，并对销量、售价、成本、毛利率、资本开支和估值倍数给出明确假设。估值方法必须匹配商业模式：

| 企业类型 | 优先估值方法 |
| --- | --- |
| 稳定盈利制造或消费企业 | PE、自由现金流收益率、DCF |
| 重资产周期企业 | PB-ROE、EV/EBITDA、重置成本、周期中枢利润 |
| 多业务集团 | 分部估值加总，并扣除净负债和控股折价 |
| 尚未稳定盈利的成长企业 | EV/Sales、单位经济和远期现金流，严格限制远期假设 |
| 资源企业 | 储量、成本曲线、商品价格情景和NAV |

$$
{\text{情景预期收益率}}
=\frac{\text{情景合理价值}-\text{当前价格}+\text{持有期分红}}{\text{当前价格}}
$$

输出不得只给“买入/卖出”。至少给出：

- 当前价格需要哪些产业和盈利假设才能成立
- 悲观、基准和乐观情景的合理价值区间与关键输入
- 基准情景潜在收益、悲观情景下行风险和收益风险比
- 立即介入、等待财报验证、等待价格回撤、仅跟踪或排除的条件
- 三个最重要的催化剂、三个最重要的风险和明确证伪阈值

最终投资动作必须与数值或可观察事件绑定：

| 触发条件 | 产业判断变化 | 盈利预测变化 | 估值影响 | 投资动作 | 失效期限 |
| --- | --- | --- | --- | --- | --- |
| 价格高位且长协继续跟涨 |  |  |  |  |  |
| 价格仍涨但斜率连续放缓 |  |  |  |  |  |
| 新增有效产能提前形成 |  |  |  |  |  |
| 下游订单取消、延期或降规格 |  |  |  |  |  |
| 利润率见顶回落 |  |  |  |  |  |
| 财报达标但低于价格隐含预期 |  |  |  |  |  |

不得只写“关注扩产风险”“等待验证”等无边界表述。需要说明等待哪个数据、最迟等待到何时、达到什么阈值改变情景权重，以及未达到时采取什么动作。

无法获得可靠一致预期时，不得伪造市场预测；可使用财报、公司指引和透明假设反推当前价格隐含的盈利要求。

### 第十二步：判断周期位置并建立监控面板

从以下信号判断周期阶段：

| 阶段 | 常见信号 |
| --- | --- |
| 复苏 | 库存下降、开工率回升、价格止跌、订单改善 |

| 过热 | 大规模扩产、渠道囤货、远期价格倒挂、估值极端 |
| 下行 | 新产能释放、库存上升、降价抢单、盈利预测下调 |

每月更新高频供需数据，每季度更新公司经营、产能、争议技术路线和重要共享要素，每半年重画瓶颈与国家生态位。政策敏感行业同时维护政策日历，记录征求意见、预算、招标、补贴退坡、关税、环保核查和规划考核等窗口，并跟踪政策目标、财政约束和企业行为是否按假设演化。只监控足以改变目标产业价格、交期、产量或政策优先级的外部行业，避免把研究扩张为无边界的全市场扫描。

### 第十三步：形成结论、反方论证和证伪条件

最终只保留高价值结论：

1. 当前利润池集中在哪个环节？
2. 未来1至3年利润池可能向哪里迁移？
3. 当前真正瓶颈是什么，预计持续多久？
4. 哪些国家和公司控制瓶颈，竞争优势来自哪里？
5. 哪三个数据最能验证判断？
6. 哪些变化会证明判断错误？

涉及涨价和投资时，结论必须额外用五句话明确回答：

1. 价格未来1季度、半年和1年的方向判断是什么？
2. 涨价斜率处于加速、放缓、转负还是因证据不足而未知？
3. 新增有效供给最早何时足以改变当前供需和价格？
4. 下游需求破坏与公司利润率见顶的触发阈值是什么？
5. 当前股价对应哪个预期层次，当前动作及其边界条件是什么？

答案必须包含时间窗口、指标或事件阈值和证伪条件。证据不足时写明未知及下一验证节点，不用方向正确但不可执行的模糊措辞填补。

必须主动写出最强反方观点。例如：需求可能只是补库存、在建产能被低估、替代技术提前成熟、涨价无法进入公司平均售价、市场份额数据口径不一致。

#### 条件式非线性冲击压力测试

普通悲观情景是在现有产业结构内调整变量；非线性冲击用于测试产业结构、传导关系或估值模型本身失效。只有同时满足“高脆弱性”和“高影响力”两个阈值时才启动，深度研究选择最可能改变决策的1至2个冲击进行推演。

高脆弱性指至少存在以下一个结构条件：

- 核心材料、设备、客户或地区高度集中
- 存在单一技术、专利、标准或供应来源依赖
- 地缘政治、出口管制、政府采购或价格管制影响显著
- 固定成本、沉没成本、经营杠杆或债务杠杆很高
- 替代技术已经进入中试、头部客户认证或小批量订单
- 单一终端应用贡献行业大部分增量需求
- 当前估值依赖远期高增长和高利润率同时兑现

高影响力指该冲击一旦发生，预计会改变瓶颈位置、利润池方向、基准估值关键变量或当前投资动作。若只能产生局部扰动，或已有库存、替代来源和合同安排足以吸收影响，则不启动压力测试。候选冲击先按“对结论的影响 × 与现有脆弱点的关联”排序，不追求覆盖所有黑天鹅。

压力测试不预测黑天鹅，也不为缺少依据的低概率事件填写精确概率。按照以下传导链展开：

```text
冲击事件
→ 首个受影响节点
→ 库存、订单和现金缓冲
→ 替代来源及切换时间
→ 成本、售价和产量变化
→ 现金流、资产减值和融资约束
→ 瓶颈与利润池重新分配
→ A股赢家、输家和中性公司
→ 原投资结论的失效与应对条件
```

| 冲击 | 可观察触发指标 | 首个断点 | 缓冲期 | 替代时间与成本 | 影响强度/可逆性 | 利润池迁移 | 投资结论变化 |
| --- | --- | --- | ---: | --- | --- | --- | --- |
| 技术突变 | 成本、良率和客户认证达到阈值 |  |  |  |  |  |  |
| 供应断链 | 禁运、停供、制裁或物流中断 |  |  |  |  |  |  |
| 需求塌陷 | 政策逆转、事故或客户削减资本开支 |  |  |  |  |  |  |

结论重点是识别脆弱连接点、缓冲期限、恢复能力和公司选择权。压力测试结果不直接并入基准估值；只有触发指标出现并改变发生条件时，才调整情景权重、合理价值和投资动作。

## 证据规范

### 来源优先级

1. 公司年报、招股书、交易所公告和专利文件

## 禁止事项

- 不以股价涨跌反推产业基本面
- 不从概念股名单倒推产业链
- 不把股价上涨简单等同于预期已充分反映
- 不把价格仍在上涨等同于涨价斜率仍能维持
- 不使用估值基准日之后公开的信息解释当时的投资决策
- 不把框架协议、意向订单或授予上限全部计入收入
- 不用单一估值倍数比较商业模式和周期位置不同的公司
- 不在缺少一致预期时虚构市场盈利预测
- 不用公告后的盈利预测解释公告前市场定价，也不把单一机构预测称为一致预期
- 不把单一研报、公司宣传或媒体报道当作完整证据
- 不用挂牌价、询盘价或零散订单代表行业成交价
- 不把宣布扩产等同于有效供给即将释放
- 不把投产日期等同于达到稳定良率、完成认证并形成可销售有效供给的日期
- 不用低规格或未认证产能抵消无法兼容的高规格供给缺口
- 不把技术可行等同于经济可行和规模量产
- 不把补贴、低能源价格或宽松环保标准形成的条件性成本优势直接当作长期护城河
- 不把公司叙事与市场定价的差异自动认定为可交易预期差
- 不让未通过删除测试的外部产业进入模型、图谱和监控面板
- 不因某环节高增长就忽略其低业务占比和低资本回报
- 不将峰值利润率或最新单季利润机械年化为长期稳态盈利
- 不用“关注风险”“等待验证”等无时间、指标和动作边界的措辞代替投资结论
- 不给缺少统一口径的市占率制造虚假精度
- 不把思维导图截图当作数据源，图谱事实必须保留节点、关系和证据
- 不只写支持主线的证据，必须保留冲突数据和反方解释
