# AlphaEar 信号跟踪 Skill

## 概述

本 Skill 提供投资信号跟踪与更新逻辑。基于新的市场信息评估现有信号的演变状态（强化、弱化、证伪或不变）。

## 能力

### 信号演变跟踪（AI 工作流）

AI 作为跟踪器，使用 `references/PROMPTS.md` 中的提示词执行以下工作流：

**工作流：**
1. **调研**：使用「金融调研员」提示词，收集与信号相关的事实和价格数据。
2. **分析**：使用「金融分析师」提示词，生成初始投资信号（InvestmentSignal）。
3. **跟踪**：对已有信号，使用「信号跟踪」提示词评估其演变（强化/弱化/证伪）。

**核心逻辑：**

- **输入**：现有信号状态 + 新信息（新闻/价格）
- **处理**：
  1. 将新信息与信号论点对比
  2. 判定影响方向（正面/负面/中性）
  3. 更新置信度和强度
- **输出**：更新后的信号（JSON 格式）

### 信号状态类别

| 状态 | 说明 |
|------|------|
| 强化 (Strengthened) | 新信息进一步验证了信号论点 |
| 弱化 (Weakened) | 新信息部分削弱了信号论点 |
| 证伪 (Falsified) | 新信息完全推翻了信号论点 |
| 不变 (Unchanged) | 新信息与信号无显著关联 |
