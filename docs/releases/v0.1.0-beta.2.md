# RT-ResearchFlow v0.1.0-beta.2

这是 RT-ResearchFlow 的第二个公开测试版本，重点补齐产业研究的数据链路、主动资讯提醒和公开版本的录屏展示体验。

> 本项目不是荐股机器人，不承诺收益，不提供自动交易。所有结论都应由用户结合原始证据独立判断。

## 下载与校验

- Windows 10/11 x64：`RT-ResearchFlow-Setup-0.1.0-beta.2-x64.exe`
- 完整性校验：下载同一 Release 中的 `SHA256SUMS.txt`，在 PowerShell 执行：

```powershell
Get-FileHash .\RT-ResearchFlow-Setup-0.1.0-beta.2-x64.exe -Algorithm SHA256
```

输出应与 `SHA256SUMS.txt` 中的哈希一致。当前测试版尚未提供代码签名，Windows 可能显示 SmartScreen 提示；请只从本仓库 Releases 页面下载安装包。

## 本版本更新

- 产业研究项目现在支持永久删除，并在删除前检查活动生成、行情同步和深度研究，避免留下不完整状态。
- 产业研究的公司补全升级为完整链路补全：继续生成证券映射、生态位关系、主营构成、业务暴露、财务时间轴和新报告，不再只追加公司名称。
- 新增高优先级资讯主动提醒；点击提醒直接打开对应资讯原文，不自动触发 AI 分析。
- 补齐日 K 换手率采集和历史缺口恢复，改善行情与研究事实覆盖。
- 修复 Mermaid 图表被误判为普通代码块、设置页横向留白和产业研究集成测试不稳定问题。
- 深度研究的产业项目选择器改为窗口内渲染，OBS 等窗口采集可以录到展开菜单，并支持项目搜索和键盘操作。

## 安装、升级与卸载

- 安装器支持当前用户安装和自选安装目录，并创建桌面与开始菜单快捷方式。
- 应用数据保存在安装目录下的 `data` 目录。由 beta.1 升级到 beta.2 会保留该目录，不覆盖已有数据库、配置和备份。
- 卸载时会询问是否同时删除本地数据，默认选择为保留。升级或卸载前建议备份整个 `data` 目录。

## AI 与数据源

- 首次启动不要求 AI Key 或 Tushare Token，可以先使用公开数据源体验基础能力。
- AI 分析、深度研究和多视角复核需要用户自行配置兼容的模型服务。
- Tushare 为可选数据源；部分财务、筹码、题材和策略数据是否可用取决于账号权限。
- 公开接口没有可用性承诺，来源限流、字段变化、休市和网络异常都可能造成数据缺口。

## 已知限制

- 本次只提供 Windows x64 安装包，macOS 尚未纳入发布验收。
- 安装包尚未进行商业代码签名。
- 零 Key 路径下的数据覆盖不等同于完整 Tushare 权限。
- 深度研究的质量和耗时取决于模型、网络、问题范围和可获得证据，不能保证每次形成完整结论。
- 应用不执行下单、自动交易、仓位控制或收益预测。
