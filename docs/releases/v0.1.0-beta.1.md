# RT-ResearchFlow v0.1.0-beta.1

这是 RT-ResearchFlow 的首个公开测试版本。它面向希望在本地整理事实、沉淀研究过程并持续复盘的 A 股个人投资者。

> 本项目不是荐股机器人，不承诺收益，不提供自动交易。所有结论都应由用户结合原始证据独立判断。

## 下载与校验

- Windows 10/11 x64：`RT-ResearchFlow-Setup-0.1.0-beta.1-x64.exe`
- 完整性校验：下载同一 Release 中的 `SHA256SUMS.txt`，在 PowerShell 执行：

```powershell
Get-FileHash .\RT-ResearchFlow-Setup-0.1.0-beta.1-x64.exe -Algorithm SHA256
```

输出应与 `SHA256SUMS.txt` 中的哈希一致。当前测试版尚未提供代码签名，Windows 可能显示 SmartScreen 提示；请只从本仓库 Releases 页面下载安装包。

## 安装、升级与卸载

- 安装器支持当前用户安装和自选安装目录，并创建桌面与开始菜单快捷方式。
- 应用数据保存在安装目录下的 `data` 目录。升级流程会保留该目录，不覆盖已有数据库、配置和备份。
- 卸载时会询问是否同时删除本地数据，默认选择为保留。删除前建议备份整个 `data` 目录。
- 从早期开发构建升级到本测试版前，也建议先手动备份数据目录。

## 本版本包含

- 本地资讯采集、全文检索、去重、来源与时间追溯。
- 观察池、组合、个股趋势、筹码结构和数据质量诊断。
- 盘前情景推演、竞价确认、盘后验证与历史校准。
- 普通 AI 资讯分析、研究讨论、可恢复深度研究和多视角复核。
- 产业研究、策略实验、回测评估与决策复盘工作台。
- SQLite 本地账本、敏感凭据主进程隔离和显式联网边界。

## AI 与数据源

- 首次启动不要求 AI Key 或 Tushare Token，可以先使用公开数据源体验基础能力。
- AI 分析、深度研究和多视角复核需要用户自行配置兼容的模型服务。
- Tushare 为可选数据源；部分财务、筹码、题材和策略数据是否可用取决于账号权限。
- 公开接口没有可用性承诺，来源限流、字段变化、休市和网络异常都可能造成数据缺口。界面中的采集时间、事实时间和质量状态属于判断的一部分。

## 已知限制

- 本次只提供 Windows x64 安装包，macOS 尚未纳入发布验收。
- 安装包尚未进行商业代码签名。
- 零 Key 路径下的数据覆盖不等同于完整 Tushare 权限。
- 深度研究的质量和耗时取决于模型、网络、问题范围和可获得证据，不能保证每次形成完整结论。
- 应用不执行下单、自动交易、仓位控制或收益预测。
