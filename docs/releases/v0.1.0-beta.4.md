# RT-ResearchFlow v0.1.0-beta.4

这是 RT-ResearchFlow 的第四个公开测试版本，重点完善零 Key 新用户的数据初始化、公共历史日线回补和大盘云图交互体验。

> 本项目不是荐股机器人，不承诺收益，不提供自动交易。所有结论都应由用户结合原始证据独立判断。

## 下载与校验

- Windows 10/11 x64：`RT-ResearchFlow-Setup-0.1.0-beta.4-x64.exe`
- 完整性校验：下载同一 Release 中的 `SHA256SUMS.txt`，在 PowerShell 执行：

```powershell
Get-FileHash .\RT-ResearchFlow-Setup-0.1.0-beta.4-x64.exe -Algorithm SHA256
```

输出应与 `SHA256SUMS.txt` 中的哈希一致。当前测试版尚未提供代码签名，Windows 可能显示 SmartScreen 提示；请只从本仓库 Releases 页面下载安装包。

## 本版本更新

- 新用户未配置 Tushare Token，或 Tushare 权限不足时，可以使用公共证券池和公共历史日线完成基础数据初始化。
- 东方财富、新浪和腾讯历史行情统一转换为项目内部 OHLCV 口径，明确处理成交量、成交额、涨跌幅和交易日边界，并保存来源追踪信息。
- 公共补采采用全局单并发、请求间隔、批次暂停、失败熔断和冷却到期续跑；全市场正常回补预计约 97 分钟，产品界面统一表达为“通常约 2 小时”。
- 已有完整本地日线会直接跳过联网；Tushare 可用时仍优先使用原有路径，公共来源作为零 Key 和权限受限场景的受控降级。
- 早盘集合竞价回看历史交易日时，“现价”使用目标交易日收盘价，不再错误依赖当前实时行情。
- 修复大盘云图左右区域同时出现两个悬浮详情的问题；右上角下拉菜单改为窗口内绘制，录屏能够正常捕获。
- 大盘云图恢复“盘中每 N 分钟滚动动量”的原始语义，并明确区分盘中滚动、午盘回放、今日收盘回放和上一交易日收盘回放。

## 安装、升级与卸载

- 安装器支持当前用户安装和自选安装目录，并创建桌面与开始菜单快捷方式。
- 应用数据保存在安装目录下的 `data` 目录。由 beta.1、beta.2 或 beta.3 升级到 beta.4 会保留该目录，不覆盖已有数据库、配置和备份。
- 卸载时会询问是否同时删除本地数据，默认选择为保留。升级或卸载前建议备份整个 `data` 目录。

## AI 与数据源

- 首次启动不要求 AI Key 或 Tushare Token，可以先使用公共数据源完成基础数据准备。
- AI 分析、深度研究和多视角复核需要用户自行配置兼容的模型服务。
- Tushare 仍是可选增强数据源；部分财务、筹码、题材和策略数据是否可用取决于账号权限。
- 公共历史日线主要用于补齐本地研究基座，不承担实时交易行情职责。
- 公共接口没有可用性承诺，来源限流、字段变化、休市和网络异常都可能造成数据缺口。

## 已知限制

- 本次只提供 Windows x64 安装包，macOS 尚未纳入发布验收。
- 安装包尚未进行商业代码签名。
- “通常约 2 小时”是正常来源状态下的全市场回补估算；若公共来源多次触发冷却，实际完成时间可能超过两小时。
- 首次回补会保留已经成功写入的股票，失败或中断后可继续执行，不承诺一次请求覆盖全部证券。
- 零 Key 路径不等同于完整 Tushare 权限，财务、筹码、题材和部分策略数据仍可能需要相应权限。
- 应用不执行下单、自动交易、仓位控制或收益预测。
