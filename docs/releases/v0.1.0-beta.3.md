# RT-ResearchFlow v0.1.0-beta.3

这是 RT-ResearchFlow 的第三个公开测试版本，重点完善市场复盘的历史可追溯性、行业层级分析和早盘竞价数据完整性。

> 本项目不是荐股机器人，不承诺收益，不提供自动交易。所有结论都应由用户结合原始证据独立判断。

## 下载与校验

- Windows 10/11 x64：`RT-ResearchFlow-Setup-0.1.0-beta.3-x64.exe`
- 完整性校验：下载同一 Release 中的 `SHA256SUMS.txt`，在 PowerShell 执行：

```powershell
Get-FileHash .\RT-ResearchFlow-Setup-0.1.0-beta.3-x64.exe -Algorithm SHA256
```

输出应与 `SHA256SUMS.txt` 中的哈希一致。当前测试版尚未提供代码签名，Windows 可能显示 SmartScreen 提示；请只从本仓库 Releases 页面下载安装包。

## 本版本更新

- 市场共振支持按交易日回看日级快照，并提供前后交易日导航、回到最新和历史补采入口。
- 一级行业默认完整展示，支持按需展开二级行业，比较二级行业、所属一级行业和市场基准的相对表现。
- 行业云图改为轻量刷新和二级行业成分按需读取，降低公共数据源限频对使用体验的影响。
- 午休、盘后和休市日启动时可恢复最近有效交易时段的行业动量，盘后复盘不再因缺少运行中采样而显示空白。
- 板块资金支持按已有真实存档回看历史交易日，历史模式与最新实时视图隔离，不使用其他日期数据回填。
- 修复早盘竞价候选过早缓存后，新增候选长期缺失 3 日和 5 日涨跌的问题；增加本地优先补齐、增量收敛和覆盖状态反馈。

## 安装、升级与卸载

- 安装器支持当前用户安装和自选安装目录，并创建桌面与开始菜单快捷方式。
- 应用数据保存在安装目录下的 `data` 目录。由 beta.1 或 beta.2 升级到 beta.3 会保留该目录，不覆盖已有数据库、配置和备份。
- 卸载时会询问是否同时删除本地数据，默认选择为保留。升级或卸载前建议备份整个 `data` 目录。

## AI 与数据源

- 首次启动不要求 AI Key 或 Tushare Token，可以先使用公开数据源体验基础能力。
- AI 分析、深度研究和多视角复核需要用户自行配置兼容的模型服务。
- Tushare 为可选数据源；部分财务、筹码、题材和策略数据是否可用取决于账号权限。
- 公开接口没有可用性承诺，来源限流、字段变化、休市和网络异常都可能造成数据缺口。
- 历史页面只展示本地已有或显式补采成功的真实事实，不以最新行情伪造旧交易日数据。

## 已知限制

- 本次只提供 Windows x64 安装包，macOS 尚未纳入发布验收。
- 安装包尚未进行商业代码签名。
- 历史回看范围取决于本地已经保存的交易日事实，早期未采集日期可能不可用。
- 零 Key 路径下的数据覆盖不等同于完整 Tushare 权限，公共接口限频时会保留已有快照并降级提示。
- 深度研究的质量和耗时取决于模型、网络、问题范围和可获得证据，不能保证每次形成完整结论。
- 应用不执行下单、自动交易、仓位控制或收益预测。
