# Windows 公开测试版干净机验收

本清单用于 Draft Release 的人工发布门禁。执行环境应为未安装过 RT-ResearchFlow、没有项目源码、没有开发环境变量的 Windows 10/11 x64 普通用户账户。

## 1. 产物与完整性

- [ ] 只从当前 Draft Release 下载 Windows x64 安装包和 `SHA256SUMS.txt`。
- [ ] 安装包名称与 `package.json` 版本完全一致。
- [ ] `Get-FileHash <安装包> -Algorithm SHA256` 与校验文件一致。
- [ ] 文件属性显示产品名 RT-ResearchFlow、正确版本和项目图标。
- [ ] 已知未签名版本会触发 SmartScreen；除此之外没有杀毒软件或系统完整性告警。

## 2. 首次安装

- [ ] 普通用户可以完成安装，不要求管理员权限。
- [ ] 默认安装目录和自选安装目录各验证一次。
- [ ] 桌面和开始菜单快捷方式名称、图标及启动目标正确。
- [ ] 安装完成后主窗口默认 1680x960，可最大化，不允许拖动改变普通窗口尺寸。
- [ ] 安装目录下创建 `data`，数据库、配置、日志和备份没有落入源码目录或用户桌面。

## 3. 零 Key 首次旅程

- [ ] 不配置 AI Key、Tushare Token 或搜索凭据即可启动并进入今日看板。
- [ ] 可以查看默认资讯来源、查询公开数据支持的单股信息并建立观察项。
- [ ] 需要额外凭据的功能明确显示未配置、数据缺口或恢复入口，不出现无限 Loading、空白页或崩溃。
- [ ] 页面加载不会自动触发深度研究、付费模型调用或未授权联网。
- [ ] 退出后重新启动，零 Key 状态和本地数据保持一致。

## 4. 可选配置

- [ ] 配置一组测试 AI Provider 后，普通资讯分析可以完成；删除配置后凭据不会出现在日志、页面源代码或研究证据中。
- [ ] 配置具备相应权限的测试 Tushare Token 后，数据页会展示真实覆盖状态；无权限接口稳定降级，不暴露 Token。
- [ ] 主动触发联网研究时能够看到进度、来源和终态；取消或失败后可以按界面允许的方式恢复或重试。

## 5. 数据保留与升级

- [ ] 备份整个 `data` 目录，并记录数据库文件数量与一个可识别的测试观察项。
- [ ] 使用同一 `appId` 的前一候选安装包建立数据，再安装当前候选包。
- [ ] 升级后测试观察项仍存在，Migration 完成且没有生成空白替代库。
- [ ] 模拟文件占用或不可写目录时，安装器停止更新并保留原数据，不留下被误认为成功的新版本。
- [ ] 用升级前备份恢复到隔离目录时，备份可读取且不含真实持仓或生产凭据。

首个公开测试版如果没有可用的前一候选安装包，必须记录“未验证”而不是勾选通过；Draft Release 保持不公开，直到用内部候选包补齐该项。

## 6. 卸载

- [ ] 卸载时明确询问是否删除本地数据，默认选择为保留。
- [ ] 选择保留后重新安装，原测试观察项能够恢复。
- [ ] 第二次卸载选择删除后，程序文件、快捷方式和安装目录内 `data` 按预期移除。
- [ ] 卸载不删除安装目录之外的文件，不影响其他应用数据。

## 7. 发布判定

记录测试机器版本、安装包 SHA256、执行人、时间和每个失败项的 Issue 链接。任何以下问题都阻断发布：

- 无法安装、启动、升级或卸载。
- 数据丢失、空库替换旧库或卸载越界删除。
- 凭据、持仓、数据库、本机路径进入安装包或普通日志。
- 零 Key 路径崩溃，或未授权触发联网、模型与交易相关动作。
- 安装包名称、版本、哈希或应用身份不一致。

全部必需项通过后，才将 Draft Release 发布为 Prerelease。
