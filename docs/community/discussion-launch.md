# GitHub Discussions 首发内容

启用 Discussions 后创建 `Announcements`、`Q&A`、`Ideas`、`Show and tell` 四个分类，并发布、置顶以下三篇内容。Issue 只承接可复现 Bug、安全问题之外的确定开发任务；问题、想法和使用方式进入 Discussions。

## 《欢迎来到 RT-ResearchFlow》

建议分类：`Announcements`

RT-ResearchFlow 是一个本地优先、证据可追溯、能够持续复盘的 A 股个人投研工作台。

这里适合讨论安装和配置、数据工作流、研究方法、功能想法，以及你如何使用本地事实、AI 辅助和复盘账本。项目不是荐股机器人，不承诺收益，不提供自动交易；请把事实、推断和个人观点明确区分。

开始使用：

1. 从 Releases 下载最新 Windows x64 测试版，并核对 SHA256。
2. 首次启动无需 AI Key 或 Tushare Token，先完成零 Key 基础体验。
3. 安装或使用问题发到 `Q&A`，功能建议发到 `Ideas`，工作流分享发到 `Show and tell`。
4. 可复现 Bug 使用 Issue 模板；漏洞和凭据暴露使用 Security 页面的私密报告。

分享截图、日志和研究案例前，请移除 API Key、Token、真实持仓、数据库和个人路径。

## 《社区版能力与项目边界》

建议分类：`Announcements`

当前公开社区版覆盖以下主要能力：

- 本地资讯采集、全文检索、去重和来源追溯。
- 观察池、组合、个股趋势、筹码结构与数据质量诊断。
- 盘前情景、竞价确认、盘后验证和历史校准。
- 普通 AI 分析、研究讨论、可恢复深度研究和多视角复核。
- 产业研究、策略实验、回测评估与决策复盘。
- SQLite 本地账本、主进程凭据隔离和显式联网边界。

首次体验不要求 AI 或 Tushare。AI 研究需要用户自行配置兼容模型；Tushare 是可选数据源，具体覆盖取决于账号权限；公开接口可能限流、延迟或变更，因此采集时间、事实时间和质量状态必须与结论一起查看。

项目不会执行下单、自动交易、仓位控制、目标价或收益承诺。对“确定涨跌”“直接荐股”“后台自动交易”等诉求不会纳入产品路线。

社区讨论和截图只以公开仓库实际拥有的能力为准。未公开代码、内部规划或无法在社区版复现的功能，不作为支持承诺。

## 《v0.1.0-beta.1 使用反馈集中帖》

建议分类：`Announcements`

`v0.1.0-beta.1` 是 RT-ResearchFlow 的首个公开测试版本。本帖集中收集安装、首次体验、数据覆盖和研究工作流反馈。

反馈时请说明：

- Windows 版本和安装方式。
- 是否为零 Key、是否配置 Tushare、是否配置 AI Provider。
- 完成了哪条用户旅程，在哪一步遇到问题。
- 预期结果、实际结果和可复现步骤。
- 经过脱敏的截图、错误码或短日志。

请不要在本帖粘贴 API Key、Token、数据库、真实持仓或完整日志。稳定复现的 Bug 请另建 Issue，并在这里附 Issue 链接；需要私密处理的安全问题请使用 Security 页面。

首轮重点观察：安装与卸载、零 Key 首次价值、数据缺口解释、深度研究进度与恢复、盘前结论可读性，以及应用在不同 Windows 缩放比例下的表现。
