# 欢迎来到 RT-ResearchFlow

RT-ResearchFlow 是一个本地优先、证据可追溯、能够持续复盘的 A 股个人投研工作台。

它试图解决的不是“让 AI 告诉我明天买什么”，而是另一类更长期的问题：每天接触到的资讯、行情、产业资料和个人判断，怎样被整理成可以回看、质疑、修正和验证的研究记录。

项目把本地事实、联网取证、AI 辅助和复盘账本放在同一条工作流里，但不会替用户越过研究过程。来源、事实日期、数据缺口、反证和未知项，应当和结论一起被看见。

> RT-ResearchFlow 不是荐股机器人，不承诺收益，不提供自动交易。项目输出用于信息整理、研究记录和历史验证，不构成投资建议。

## 这里适合谁

这里更适合以下使用者：

- 希望把分散的新闻、行情、公告和产业资料沉淀到本地的人。
- 希望知道一项判断依据什么、缺少什么，并能在之后复盘的人。
- 愿意自己核对事实，把 AI 当作研究助手而不是最终裁判的人。
- 关心数据来源、时间边界、隐私和运行成本的人。
- 愿意报告可复现问题，或分享真实研究工作流的人。

如果你寻找的是自动下单、确定涨跌、目标价、仓位指令或收益承诺，这个项目并不适合你。这些能力也不会进入当前产品边界。

## 从哪里开始

1. 前往 [Releases](https://github.com/caoritian002-wq/RT-ResearchFlow/releases) 下载最新 Windows x64 测试版。
2. 同时下载 `SHA256SUMS.txt`，安装前核对文件哈希。
3. 首次启动不必配置 AI Key 或 Tushare Token，先完成零 Key 基础体验。
4. 需要更完整的数据或 AI 研究时，再按需配置自己的 Tushare 和兼容 AI Provider。
5. 遇到问题时，先根据下方分流选择正确入口。

当前公开测试版尚未提供商业代码签名，Windows 可能显示 SmartScreen 提示。请只从本仓库 Releases 页面下载安装包，不要使用第三方转载文件。

## 讨论时请保留证据，也保护隐私

有价值的讨论不要求观点一致，但需要区分事实、推断和个人判断。引用数据时，请尽量写明来源、事实日期和采集时间；描述问题时，请说明版本、环境、复现步骤、预期结果和实际结果。

发布截图、日志或研究案例前，请移除以下信息：

- API Key、Token、Authorization Header 和连接凭据。
- 真实持仓、成本、账户、交易记录和个人财务信息。
- SQLite 数据库、完整配置、备份和未脱敏日志。
- 用户名、电脑名、安装路径及其他可以识别个人环境的信息。

不要为了证明问题而公开敏感样本。无法脱敏但确实影响安全的问题，应通过私密安全报告提交。

## 社区如何形成价值

这个社区不以预测口号或收益截图作为质量标准。更有帮助的内容包括：

- 一条能够稳定复现的安装或功能问题。
- 一项数据缺口是如何被发现和解释的。
- 一次研究为什么改变了原判断，或为什么仍然没有结论。
- 一个工作流怎样减少重复劳动，同时保留事实和反证。
- 一项建议解决了什么真实问题，以及如何验证它确实有效。

欢迎介绍你最想用 RT-ResearchFlow 解决的研究问题。具体安装和使用问题请单独发布到 Q&A，这样后来的用户也能检索和复用答案。

### 正文

# 社区版能力与项目边界

这篇说明用于回答三个问题：公开仓库现在真正包含什么，哪些能力需要用户自己的数据或模型配置，以及哪些事情 RT-ResearchFlow 明确不会做。

当前说明以公开仓库和最新公开测试版为准。未公开代码、内部规划、尚未合并的功能和无法在社区版复现的截图，不构成社区版能力或支持承诺。

## 一句话定位

RT-ResearchFlow 是本地优先、证据可追溯、能够持续复盘的 A 股个人投研工作台。

它连接资讯、行情、产业研究、AI 研究和策略验证，但最终目标不是生成一句看似确定的答案，而是保留“当时知道什么、为什么这样判断、后来发生了什么”。

## 当前社区版包含什么

### 1. 资讯与本地事实

- RSS/Atom 资讯采集、去重、归档和 FTS5 全文检索。
- 来源、发布时间、采集时间和内容状态追溯。
- 资讯与 A 股公司、持仓风险及后续研究入口的关联。
- 数据缺失、来源异常和恢复路径的显式提示。

### 2. 个股、组合与市场观察

- 观察池、组合、近期日 K、均线、趋势事实和相对强弱。
- 筹码峰、筹码变化、支撑压力和基本面入口。
- 大盘、行业、板块资金及短线工作台中的候选复核。
- 数据质量中心、来源状态和失败诊断。

### 3. 盘前情景与盘后验证

- 盘前外部风险、持仓趋势、筹码、公告、资讯和行业事实组合。
- 08:45 初版、09:28 后竞价确认以及固定 09:30 事实边界。
- 基准、强化和风险情景，以及支持、反证、确认、失效和未知项。
- R1/R2/R3 不可变修订、盘后真实路径验证和历史校准。

盘前情景用于组织可能路径和确认条件，不是确定涨跌预测。外盘上涨不会被直接翻译为 A 股或单只股票上涨。

### 4. AI 分析、深度研究与多视角复核

- 普通资讯 AI 分析和相关 A 股公司映射。
- 可直接发起的深度研究工作台，不要求用户先创建研究讨论。
- 计划、取证、综合、审计和写回阶段反馈。
- 网页与 PDF 正文证据、来源门禁、报告与证据分层。
- 中断恢复、重新研究、单记录管理和费用账本。
- 基于同一份不可变证据的多轮多空复核。

深度研究质量取决于研究问题、可获得证据、网络、模型能力和用户配置。流程成功不等于事实完整，也不等于投资结论正确；界面会把执行状态和结论覆盖分开表达。

### 5. 产业研究、策略实验与复盘

- 产业图谱、A 股公司映射、业务暴露、财务时间轴和市场验证。
- 参数化策略条件、本地扫描、历史信号和持有期效果评估。
- 判断保存、3/7/14 日回访、日报、周报和历史结果对照。
- 从资讯、信号、判断和研究讨论形成可确认的研究增量。

策略历史表现只描述已有样本。样本不足、数据缺失或覆盖不一致时，不应被包装成高可信度胜率。

## 零 Key、可选配置与联网边界

| 能力 | 零 Key 是否可用 | 可选配置 | 说明 |
| --- | --- | --- | --- |
| 应用启动、本地账本和基础工作台 | 是 | 无 | 首次启动不要求账户体系 |
| 部分公开行情、公司资料和资讯 | 是 | Tushare 可增强 | 公共接口可能限流、延迟或变更 |
| 更完整的日线、财务、题材和筹码数据 | 部分 | Tushare Token | 实际覆盖取决于账号权限 |
| 普通 AI 分析 | 否 | 兼容 AI Provider | 由用户提供模型服务和凭据 |
| 深度研究与多视角复核 | 否 | AI Provider；联网取证还需相应配置 | 用户显式启动，记录模型、工具、Token、费用和恢复状态 |
| 盘前联网补采 | 默认关闭 | 用户显式开启或点击补采 | 不允许把事实边界之后的新信息倒灌进历史判断 |

“本地优先”不等于“永不联网”。本地已有事实先被复用；需要最新资料或存在硬缺口时，联网必须由用户配置或显式触发，并保留来源、时间和失败原因。

## 数据、隐私与安全边界

- SQLite 是本地研究账本的权威来源，数据库、配置、缓存、日志和备份保存在本机。
- AI、Tushare 和搜索凭据由 Electron 主进程管理，不应进入 renderer、研究报告或普通日志。
- 页面加载、打开抽屉和应用重启不会顺便触发付费模型或深度研究。
- Agent 联网经过受控出口，限制私网访问、危险重定向、超大响应和不受支持的内容类型。
- 模型请求结果未知时，同一研究账本不会自动重放，以避免重复费用和重复写入。
- 用户仍需自行判断所使用 Provider、数据源和网络服务的隐私政策与计费规则。

发现可能导致凭据泄露、任意文件或网络访问、数据库破坏、权限绕过的问题时，请使用 [私密安全报告](https://github.com/caoritian002-wq/RT-ResearchFlow/security/advisories/new)，不要公开披露复现细节。

## 明确不做什么

当前项目边界明确排除：

- 券商连接、自动下单和自动交易。
- 自动调仓、仓位指令和代替用户执行投资决策。
- 确定涨跌、目标价、收益承诺或“稳赚”表达。
- 用模型常识伪造缺失事实，或把搜索摘要当作正式正文证据。
- 用新数据改写旧研究账本，使历史判断看起来更正确。
- 未经用户明确动作自动联网、自动调用付费模型或遍历敏感持仓。

这不是暂时缺少几个按钮，而是产品的可信边界。相关诉求不会作为普通功能建议进入路线。

## 如何判断一个建议是否适合社区版

一个适合进入 Ideas 的建议，通常能够回答：

1. 它解决了哪个真实、可重复的研究问题？
2. 它需要哪些数据、权限和联网范围？
3. 用户如何知道结果依据什么、何时失效？
4. 失败、中断和数据不足时应该如何表现？
5. 怎样通过测试或用户旅程验证它，而不是只看演示截图？
6. 它是否仍然遵守本地优先、证据可追溯、用户显式触发和不越过交易边界？

符合这些条件的建议，请发布到 [Ideas](https://github.com/caoritian002-wq/RT-ResearchFlow/discussions/categories/ideas)。可复现缺陷请使用 [Issue 模板](https://github.com/caoritian002-wq/RT-ResearchFlow/issues/new/choose)。

## 版本与支持预期

社区版使用 `AGPL-3.0-only` 许可证。当前仍处于公开测试阶段，接口、数据覆盖和交互可能调整；维护者会优先处理安全问题、数据破坏、无法安装启动以及可以稳定复现的主流程缺陷，但不承诺服务等级、数据源可用性或投资结果。

完整安装包、版本说明和已知限制以 [Releases](https://github.com/caoritian002-wq/RT-ResearchFlow/releases) 为准。

## 安装前请先确认

- 当前只提供 Windows 10/11 x64 安装包。
- 安装包尚未提供商业代码签名，Windows 可能显示 SmartScreen 提示。

## 建议先完成这条 15 分钟旅程

这条旅程不需要真实持仓，也不要求提前配置 AI 或 Tushare：

1. 使用普通 Windows 用户完成安装并启动应用。
2. 确认主窗口、左侧导航、亮暗主题和最大化行为正常。
3. 在零 Key 状态下进入今日看板，确认页面能够正常加载且不会无限 Loading。
4. 使用公开数据支持的股票查询，查看近期行情、趋势或公司资料，并建立一个测试观察项。
5. 退出并重新启动，确认测试观察项和本地状态仍然存在。
6. 打开数据质量或配置相关页面，确认缺少 AI、Tushare 或特定来源时能够看到明确原因和下一步入口。
7. 不再使用后卸载应用，记录选择保留或删除本地数据时的实际行为。

不要为了测试导入真实账户、真实持仓或生产凭据。需要验证 AI 或 Tushare 时，请使用专门的测试配置，并在反馈前彻底脱敏。

## 本轮最需要验证什么

### 安装与系统兼容

- Windows 10/11 版本、系统缩放比例和普通用户权限下能否安装、启动与卸载。
- 默认目录、自选目录、桌面快捷方式和开始菜单是否正确。
- SmartScreen、杀毒软件或系统完整性检查是否出现安装包未签名之外的异常。

### 零 Key 首次价值

- 不配置 AI、Tushare 和搜索服务时，用户能否理解第一步该做什么。
- 公共数据覆盖不足时，页面是否解释清楚，而不是空白、无限 Loading 或给出伪结论。
- 退出重启后，本地观察项、配置和页面状态是否保持一致。

### 数据与研究工作流

- 资讯来源、事实日期、采集时间、数据缺口和恢复入口是否容易理解。
- 个股趋势、筹码、基本面和盘前情景中的结论层级是否清楚。
- 深度研究能否持续反馈进度；失败、取消或中断后能否按界面提示恢复或重新研究。
- 报告是否先给结论，证据是否能独立查看并回到原始来源。

### 数据保留与卸载

- 升级或重新安装后，本地数据是否保留。
- 卸载选择保留数据后，重新安装能否恢复测试观察项。
- 卸载选择删除数据时，是否只清理 RT-ResearchFlow 自己的文件。
