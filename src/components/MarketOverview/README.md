# MarketOverview 组件说明

## 模块功能

`MarketOverview` 是“大盘云图”一级模块的容器, 承载行业云图、市场共振和板块资金流向。FR-224 后, 顶部标题栏已经常驻展示三大指数摘要, 大盘云图内部不再额外渲染市场环境悬浮球。

FR-243 后，板块资金页优先读取东方财富概念/行业真实主力资金并保存每日观察；外部失败时先回退最近真实存档，再降级为本地“成交方向强度”。降级口径不得称为净流入，也不得生成资金决策信号。

## 实现思路

组件维护 `activeSubTab` 并写入 `localStorage.marketOverviewSubTab`, 用于恢复用户上次查看的子页面。FR-244 起，二级入口只保留 App 壳层左侧 Flyout，`MarketOverview` 不再渲染重复顶部 Tab；受控 props 和本地存储键保持兼容。

## 主要 props/state/事件流

- `activeSubTab`: 当前子页签, 可为 `industry`、`heatmap` 或 `sectorFlow`; 作为 prop 传入时由外部控制。
- `onSubTabChange`: 历史兼容回调；FR-244 页面本身不再触发，切换统一由 App 壳层 Flyout 完成。
- `IndustryHeatmap`：行业云图。
- `MarketHeatmapPanel`：市场共振工作台，比较上证、沪深300、创业板与31个申万一级行业的一分钟收益关系。
- `SectorFlow`：板块真实资金与次日竞价观察。

## 市场共振

- 主进程 `marketResonanceService` 从东方财富实时/延迟节点读取指数和行业一分钟趋势，并与行业广度、主力净额合并。
- `marketResonanceModel` 计算一分钟收益相关性、同向率、近30分钟持续性、超额收益和±5分钟移位关系；少于30个对齐分钟不输出判断。
- 页面顺序为盘面结论、紧凑市场背景、行业排序和单行业分时下钻；旧涨跌分布大图、涨跌停大图和概念标签叠图已移除。
- 页面内表格允许局部横向滚动，应用文档不得出现横向溢出；1440并列，1024上下排列。

## 特殊逻辑备忘

- 大盘云图用大色块表达行业情况, 市场环境不能以横条、卡片、面板或悬浮球常驻挤占显示空间。
- 页面级提醒和高优先级未读不在大盘云图内重复展示, 统一通过消息中心查看和跳转。
- 新增或调整子页面时，需要同步更新 `MarketOverviewSubTab` 联合类型、`MARKET_OVERVIEW_SUB_TABS` 白名单和 App 壳层二级 Flyout 配置；不得重新添加页面内同级导航。
- 板块资金首屏先展示来源、明早竞价结论、去重重点主题、风险主题和核心股，完整明细位于其后；禁止恢复跨重叠板块的“全市场净流入合计”。
- 成分抓取候选与结论必须使用同一评分排序；成分缺口降低置信度并显式说明，缺失比率保持 `null/--`。
