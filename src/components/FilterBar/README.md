# FilterBar 组件维护说明

## 模块功能

`FilterBar` 是资讯情报台中部队列的工具区, 负责展示扫描状态、未读数量、影响力分段筛选和标题/摘要搜索。手动扫描主入口由资讯页顶部状态区承载, 本组件只保留队列控制。

## 实现思路

组件直接从 `useAppStore` 读取资讯筛选条件与扫描状态, 不持有本地业务状态。影响力筛选使用分段按钮表达当前队列口径, 搜索框通过 `setFilter({ searchQuery })` 实时更新全局筛选。UI 按队列工具条维护, 影响力筛选、未读/来源口径和搜索保持在同一行, 第二行只保留轻量扫描时间与未读数说明。

## 主要 props/state/事件流

- `selectedRating`: 当前影响力筛选, 可为全部、重大、重要或一般。
- `searchQuery`: 标题与摘要搜索关键词。
- `scanStatus`: 最近扫描状态, 用于展示上次扫描时间。
- `isScanning`: 扫描执行中状态, 控制工具条状态文案。

## 特殊逻辑备忘

扫描能力沿用全局 store 既有动作, 主按钮放在资讯页顶部状态区。本组件不直接访问 IPC。工具条应保持紧凑, 控件采用轻量白底胶囊样式, 不在此处增加来源树、日期树、详情动作或第二个“立即扫描”按钮。
