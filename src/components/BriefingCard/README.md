# BriefingCard 组件维护说明

## 模块功能

`BriefingCard` 是资讯队列中的单条资讯卡片, 展示影响等级、发布时间、标题、摘要、来源、未读状态和产业链分析入口。

## 实现思路

组件保持纯展示与事件透传, 不直接读取全局状态。视觉上按资讯情报台队列行处理, 通过影响等级、来源、未读状态和影响分强化优先级: 重大/重要资讯显示验证提示, 未读资讯保留青色强调, 选中项使用青色描边和浅底。卡片需要维持紧凑密度, 避免回到大段文章卡片样式。

## 主要 props/state/事件流

- `briefing`: 当前资讯数据。
- `isSelected`: 是否为详情区当前选中资讯。
- `onClick`: 点击卡片后由父组件切换详情。
- `onChainClick`: 点击“产业链分析”后传出标题与摘要文本。

## 特殊逻辑备忘

产业链分析按钮仅在非一般影响资讯中展示。按钮点击会 `stopPropagation()`, 避免同时触发卡片选中。中部队列优先用于扫描和比较, 标题与摘要都需要限制行数, 避免单条资讯挤占首屏。
