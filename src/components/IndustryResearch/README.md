# 产业研究工作台

## 模块功能

在“AI 分析”一级导航下承载产业研究项目、结构化图谱、证据、假设、公司财报事实和完整研究报告。默认入口是“研究问题 → 自动受控取证与来源评级 → AI 按内置 Skill 连续生成 → 完整 Markdown 报告阅读 → 按需来源追溯/正式纳入 → 财务验证”。页面使用左侧项目轨和中央研究区；证据/假设账本收进右侧44px轨道的按需覆盖式抽屉，不复用旧传导抽屉作为主工作台。

## 实现思路

工作台只通过 `window.api.industryResearch` 访问主进程。结构化图谱是事实源；报告页优先渲染生成阶段产出的完整 Markdown 文档，Mermaid 与证据分区作为附录。默认新建研究打开 `ResearchGenerationDialog`，空白项目和边界表单降为高级入口。生成运行、候选证据和公司候选由主进程持久化，前端通过 `getGenerationRun` 与 `generationProgress` 恢复进度。

联网取证优先由 ChatGPT Responses API 原生 `web_search` 完成：模型自主提出 query、打开页面、执行页内查找并形成带 URL 引用的研究备忘录。工具动作、来源和正文引用保存在生成运行阶段 JSON，并转换为现有候选证据；实际引用来源优先进入代表性候选。GPT 未配置、模型不支持工具或未返回可审计来源时，自动回退 Research Tool Runtime：本地近窗资讯与既有研究证据优先召回，再叠加内置弱检索或已配置的 Tavily/Bing 增强搜索，并对官方源做“搜索页 → 详情页”两段式抓取。增强搜索密钥不是开始研究的前置条件，回退后仍可生成完整报告，但必须展示真实模式与回退原因。

信息架构按真实工作流拆分：顶部只保留紧凑生成进度与检索模式徽章；生成成功后默认进入“报告”页签阅读完整结论性 Markdown。完整候选池、query 计划、排序分、抓取失败和 GPT 工具轨迹收纳在“来源与审计”，页面用“本次结论来源”表达用途，默认只显示代表性来源并折叠工具明细。这里不是审核队列，也不显示必须清零的待办数量。用户可在报告后排除单条来源；后续同项目生成与产业讨论会携带排除 URL，最终仍引用时拒绝保存该轮结果。

新报告在完整Markdown正文之前复用共享`ResearchAuditTrace`，默认折叠展示本轮确定性审计、稳定本地证据引用、来源、事实截点和正文/证据双SHA-256。该视图只读取运行中已固化的`researchFacts`与`textAudit`；快照校验不一致时停止关联具体证据，不读取当前SQLite补造历史回放。

用户可在通过校验的报告审计中显式“对比当前事实”。renderer只提交项目与生成运行身份，主进程按北京时间当天只读重建同一主体的本地证据，并列显示已变化、新增、不再出现和未变化；结果不持久化，“不再出现”不等于历史事实已被证伪。

存在真实变化后可显式进入“事实变化复核”讨论。renderer仍不上传差异正文；主进程重新校验报告运行归属、正文和证据快照，固化双截点、有界变化摘要与当前证据快照。该动作只预填可编辑问题，不自动调用模型或生成研究增量；后续仍由用户点击既有“整理本次讨论”进入FR-239流程。

“图谱”页直接读取 `ResearchGraph.nodes/edges`，由 `industryResearchGraphModel.ts` 确定性派生分层坐标、邻接重心顺序、默认核心节点和关联子图，再由 `ResearchGraphCanvas.tsx` 使用现有ECharts渲染有向传导图。超过16节点时默认进入关联视图，1024最多显示10个、宽屏最多显示16个；点击节点切换邻接网络。完整图谱保留全部事实并在单一自适应画布中提供初始全景、拖拽、滚轮缩放及可见的放大、缩小和适应全图控制，节点间距保留可读冗余但不再扩张为超大滚动画布。孤立或循环节点按环节语义补位；损坏JSON只使对应摘要为空，不影响整图。

`ResearchSidePanel` 只永久占用44px账本轨道。证据和待证伪假设使用互斥页签的Portal覆盖式抽屉，抽屉按轨道真实视口矩形定位，避免工作区滚动或层叠上下文吞掉点击结果；默认关闭，打开不改变中央工作区宽度，支持关闭按钮和Esc。证据、假设、原文、添加与状态更新能力保持不变，“决策”页继续隐藏该轨道。

“公司与财报”是中央研究区的局部视图，不增加一级导航，也不把公司、证券、时间轴、同步选择或利润桥草稿放入 Zustand。主进程返回的 snake_case 财务行统一由 `industryResearchFinancialModel.ts` 适配为稳定视图类型；未知财务值保持 `null`，禁止显示为 0。

T1383 联合回归分两层：服务层使用真实 SQLite、完整 Migration 链以及确定性 AI/检索/财务替身，验证生成阶段、部分失败、事实门禁、版本冲突和跨重启；真实 Electron 旅程使用隔离 `userData` 的本地夹具，验证报告、来源追溯、公司财务、讨论回流和目标视口。两层都不访问真实搜索、Tushare 或 AI Provider，避免把外部额度和网络波动误判为产品回归。

FR-239 起项目头部增加“和 AI 讨论 / 继续讨论”，中央研究区增加“研究增量”。默认只展示最近批次的 3 至 7 个语义变更包；40 条以上底层节点、证据、假设、公司和回访候选收在分页高级审计中，不要求用户逐条清零。接受前可修改包标题和摘要；只有接受动作才在单事务内增量写入正式研究并创建不可变版本。

从项目进入或恢复讨论时，返回目标同时保存项目、局部页签和中央工作区滚动位置；恢复同一会话会刷新为本次进入位置，避免返回首次打开讨论时的旧页面状态。

第181阶段已经形成完整研究决策闭环：第181B保存完整Skill规则、版本化工作项、三情景、只追加决策事件、监控观测、触发求值、分组待复核和历史回放；第181C在报告后的局部“决策”页连接市场定价、透明估值、不可变快照和人工触发确认。报告仍是默认交付物，40条以上证据不会形成逐条审核队列；触发命中只进入“待复核”，确认后才与下一版决策原子提交。

## 主要状态与事件流

- AI 二级导航切换到产业研究后挂载工作台。
- 跨模块建立研究时，通过 Zustand 传入待打开项目 ID。
- 项目列表默认隐藏已归档；左侧可切换“显示已归档”，并打开清理中心。
- 项目列表读取后定位首个非归档项目；详情、报告和生成运行并行读取。
- 项目详情、报告和生成运行分别受请求序号与当前项目归属保护，过期响应不能覆盖新项目。
- 默认新建研究提交研究问题后调用 `startGeneration`，且不传当前 `projectId`，始终创建新项目；禁止把新问题写进已选中的旧项目。
- 对既有项目的再次生成只走“重试”等显式动作，不通过“新建”复用项目。
- 新建研究弹窗可配置 Tavily/Bing/自定义增强搜索；弱检索状态条也可展开同一配置面板。
- 无研究版本的项目支持归档与永久删除；一旦存在不可变研究版本只能归档。清理中心批量删除同样受主进程版本保护。
- 生成成功后默认切到“报告”页签；完整 Markdown 优先展示，弱取证时正文顶部保留证据状态声明。
- 报告关键结论可直接打开代表性原文；“来源与审计”支持代表性/完整/官方/失败来源筛选和 query 计划展开。
- 原生搜索成功时审计页展示 provider/model、工具动作数、来源数和引用数；详细 `search/open_page/find_in_page` 轨迹默认折叠。原生失败时展示自动回退受控检索，不要求用户补确认。
- “排除此来源”把候选标记为 `rejected`，不会改写已完成报告；后续生成和关联产业研究讨论不再允许最终引用该 URL。
- `confirmEvidenceCandidate` 兼容通道在产品上解释为报告后的“纳入正式证据库”。主进程校验项目、运行和候选归属，在事务中幂等写入 `estimate` 支持材料，`primarySourceConfirmed` 保持 `false`，不构成来源全局可信背书，也不改写已完成报告。
- 公司候选中的唯一精确、仍上市沪深北证券在报告正式写回时自动登记为 `candidate` 项目公司并进入公司、财报与决策核验层；歧义、无匹配、非A股或已排除候选继续人工处理。自动登记不确认业务暴露、财务事实或投资结论。
- 历史成功报告若只有公司候选而缺少项目公司，打开公司列表或决策页时会用本地候选与 `stock_basic_cache` 幂等补登记；该兼容动作不搜索、不调用模型、不访问Tushare。
- “决策”是项目中央研究区的局部页签，不新增一级或二级导航；内部固定为“当前研判 / 待复核 / 监控与回访 / 历史”。
- 当前研判只读取所选项目公司和证券的本地事实；行情按最近共同交易日、个股前复权和受控指数计算20/60/120/250日窗口，页面挂载不会自动联网。
- 市场同步必须由用户显式发起，并按个股日线、调整因子、点时估值和指数日线分段返回；空响应、权限不足或部分失败保留最后成功缓存。
- 三情景估值固定支持PE、PB-ROE、EV/EBITDA、DCF、SOTP和NAV。输入只能选择当前公司且单位兼容的本地事实，或填写有说明的人工假设；缺值、负值、单位冲突和反推无解保持阻断。
- 冻结操作在单一事务保存不可变市场与估值快照；`wait_price` 必须绑定同项目、同公司的非阻断快照，历史回放不读取后来刷新的当前价格。
- 项目或证券切换清空上一上下文的估值与快照草稿；普通局部页签切换保留公司、证券和四段视图，AI讨论返回恢复同一局部状态。
- 项目边界可编辑和归档；边界变化由后端标记待复核。
- 变更包可接受、暂存或忽略；暂存使用中性反馈，不形成全局红色待办。高风险包自动展开可信边界，普通接受不能把 AI、媒体或二手材料升级为事实。
- 事实候选只有在接受对话框中由用户确认具体 HTTP(S) 一级来源后才能写为 `fact`；这是一项窄事实升级门禁，不是要求用户审核几十条普通证据。
- 接受成功后刷新项目事实、批次归属和研究版本；未关联项目的讨论可在接受时选择现有项目或创建草稿，批次归属与正式实体在同一事务固化。
- “研究版本”展示不可变快照及来源讨论反向链接；来源讨论删除后保留版本和来源摘要，但不显示可点击入口。
- “高级导入”只支持规定的光纤五文件迁移档案，校验 UTF-8、文件名、大小和 SHA-256 后生成四个语义变更包，不直接改写项目事实。
- 事实证据必须绑定网址或来源编号并人工确认；估算可独立保存但不升级为事实。
- 假设必须填写最低成本反证；状态变化必须填写原因并追加历史事件。
- 图谱页通过结构化 JSON 维护节点和关系，保存前完整保留指标、证据绑定、强度和更新时间字段。
- 图谱字段转换集中在可独立测试的纯函数中，定向测试锁定完整字段往返和并发版本快照。
- 快速传导建立草稿后，通过 Zustand 传入项目 ID 并定位当前项目。
- 公司列表和公司事实分别使用独立请求序号；项目、公司或证券切换时立即清空上一上下文，过期响应不能写回当前视图。
- 公司事实并行读取公告证据、业务暴露、财务时间轴、财务验证、九数据集同步状态和最新利润桥；单个读取失败会恢复加载状态并在当前视图显示错误，不保留旧公司事实。
- 时间轴筛选、同步数据集选择、利润桥键输入和实际查询键使用独立状态，输入过程不会触发整组事实重载。
- 公司与证券通过公司弹窗维护；公告弹窗只登记或维护用户确认的官方原文链接、标题、日期和摘要，不抓取或保存正文。
- 暴露保存前执行状态门禁；`confirmed` 必须绑定研究节点、事实日期和当前公司下人工确认的官方公告证据。
- 利润桥保存只追加新版本；`VERSION_CONFLICT` 时保留用户草稿和冲突信息，刷新后由用户决定是否重试。
- 单公司同步必须明确选择证券和一至九个数据集；各数据集独立展示成功、空响应、权限不足或失败，最后成功事实继续保留。

## 特殊逻辑备忘

- `industryResearchService` 必须静态链接 `industryResearchGenerationService`；共享错误类型放在无依赖模块中，避免循环初始化。主进程是单文件构建，禁止用 `require('./industryResearchGenerationService')` 延迟加载，否则源码测试可通过但真实Electron运行时会找不到独立文件。
- 市场与估值服务也必须由handler静态链接；生产构建后的真实Electron旅程必须实际调用 `getDecisionWorkbench` 和 `getDecisionReplay`，不能只以源码单测代替打包验证。
- `daily_close_cache` 继续保存不复权行情；产业研究前复权只在局部服务中组合 `adj_factor`，不得改变FR-229日线保留和回测口径。
- 同项目可比公司少于3家、历史估值有效样本少于120日时不显示伪排名或伪分位；缺失值统一显示“不可用”，不能格式化为0。
- 快速传导推荐股票不得自动登记为已验证公司或证券节点。
- 快速传导只导入链组、命中概念、节点和关系，种子统一为估算。
- 图谱保存携带打开维护区时的 `graphUpdatedAt`；遇到 `VERSION_CONFLICT` 提示刷新后重试，禁止静默覆盖。
- 财务时间轴按实际公告日期优先排序，同报告期的不同来源、报表类型和修订版本并存；累计值、派生单季和阻断事实不得合并成同一条记录。
- `fina_mainbz` 只能形成候选暴露，不能自动升级为已确认，也不能覆盖人工“无法拆分”或排除状态。
- 财务验证只读取本地事实，缺失、阻断和上游失败保持稳定原因；不借其他数据集或 AI 补零。
- 千问 `enable_search` 不是 GPT 原生搜索或受控联网取证完成条件；原生工具不可用时研究回退既有检索并继续，但必须展示检索模式、回退原因与待补来源。
- 候选证据默认只保存 URL、标题、摘要和有限摘录，不默认保存全文；搜索结果页不得作为有效证据正文。
- 图谱/假设/公司/报告尽量引用候选证据 ID；无引用内容标记“无证据支撑”，报告分区展示有证据支撑、仅模型推断和待补来源。
- 新版报告分区的 `supportedFindings` 使用 `{ text, candidateIds }`；读取层兼容旧 `string[]`，跨项目或不在精选集合中的引用会被过滤。
- 报告页以完整 Markdown 正文为主，不在正文前重复展示 `supportedFindings` 摘要卡；来源打开、筛选和正式纳入统一在“来源与审计”完成，证据分区只在正文后按需展开。
- AI 生成的研究截止日只接受用户显式值；未设置时由主进程按任务启动时的北京时间日期确定并写回项目。模型返回的日期和模型知识截止日均无权覆盖，读取旧运行时会过滤引用错误截止日的时间冲突。
- `ResearchDatePicker` 保持产业研究估值日的默认文案与未来日期门禁，同时提供可选日期下限和通用无障碍文案，供策略回测等本地事实页面复用；复用方不得复制第二套原生日历。
- 候选池上限允许达到 48 条，向模型继续只提供精选 TopN；候选数量和状态不会暂停 `retrieve → report` 连续生成。
- 首批本地语料只含近窗资讯与既有研究证据；不自动抓取公告全文，不生成 AI 财务数值、估值、市占率、目标价或交易指令。
- 删除项目只清项目级事实（图谱、证据、假设、生成运行、候选、项目公司状态、利润桥）；共享公司、证券与财务事实保留。清空全部需输入确认词“删除全部”。
- 研究版本通过 SQLite 触发器禁止更新和删除；项目外键使用 `ON DELETE RESTRICT`。界面禁用删除只是提前解释，主进程约束仍是最终门禁。
