# shared 组件模块

## 模块功能

`shared` 目录承载跨页面复用的组件和绘制工具, 包括回测抽屉、通用右侧抽屉、股票日 K 与筹码峰抽屉、技术因子摘要、术语提示等。

## 实现思路

共享组件保持业务输入简单, 由调用方负责提供股票、回测或展示数据。组件内部只处理布局、格式化和局部交互, 避免直接持有页面级状态。

## 主要 props/state/事件流

- `BacktestModal`: 由短线策略页面传入 `open/onClose`, 内部读取回测状态、进度和明细。
- `RightDrawer`: Portal渲染的全窗口模态右侧抽屉。支持标题、说明、操作区、50%暗色蒙层、背景滚动锁定、焦点约束与恢复、Esc/按钮关闭、左边缘拖动与键盘调宽；面板覆盖Electron标题栏并占满视口高度，调用方可按嵌套宿主提升 `zIndex`。
- `StockKlineChipDrawer`: 接收股票代码、名称、关闭和进入完整走势回调, 用于策略表格行的快捷行情查看。展示 30/60/120 日日 K、MA/BOLL、终端式价格筹码剖面和技术因子, 点击 K 线可联动对应日期筹码。MA5/10/20/60 与BOLL(20,2)均基于抽屉已加载的完整日 K 本地滚动计算，不受短期技术因子缓存保留期影响；MA20同时表达BOLL中轨，不重复绘制重合线。日K与筹码hover详情均使用不透明深色表面，避免图形穿透文字。
- `StockMiniChart`: `StockKlineChipDrawer` 的兼容别名; 新调用方不得再传锚点坐标或依赖任意位置浮窗。
- `FactorSummary`: 接收技术因子数据并渲染摘要条。

## 特殊逻辑备忘

Tooltip 箭头使用旋转方块绘制, 不再使用左右粗 `border` 拼三角形, 以避免视觉检测工具将其误识别为卡片侧边强调条。

股票快捷抽屉打开后使用蒙层隔离背景并将应用根节点设为 `inert`，页面不再接受误操作；关闭后恢复原焦点和页面滚动。普通页面使用 `z-[9999]` 全窗口层级，回测和产业链整页抽屉内的调用方显式提升层级，保证股票详情位于宿主之上。1024px视口保留可辨识蒙层且不产生横向溢出，关闭按钮保持44px热区；`prefers-reduced-motion` 下关闭位移动画停用。日K继续使用既有 `lightweight-charts`，筹码峰继续使用既有Canvas绘制，不为抽屉重复引入图表库。

快捷抽屉的筹码区使用从右向左展开的价格剖面。红色只表示成本价不高于当前参考价的浮盈筹码, 绿色只表示成本价高于参考价的套牢筹码, 青色虚线表示当前参考价; 颜色不推断账户身份、未来方向或买卖动作。顶部浮盈/套牢占比先按有效价格级筹码归一化, 主峰取占比最大的价格点, “距主峰”使用 `(参考价 - 主峰价) / 主峰价`, 核心成本区使用累计筹码 15%-85% 分位。缺少参考价时浮盈、套牢和距主峰显示未知, 不伪造为 0%。

最新日期使用单侧终端价格剖面。点击历史 K 线后切换为双侧蝴蝶比较: 左侧以红绿显示所选日期, 右侧以青色显示最新日期, 两侧共享价格范围和最大占比尺度, 各自保留收盘参考线与核心成本区; 加载期间旧日期数据不会冒充当前选择。柱宽切换仅使用 180ms 展开过渡, `prefers-reduced-motion` 下直接显示终态。悬停使用固定宽度、完全不透明深色背景同时展示所选日占比、最新日占比和百分点变化, 不让筹码柱穿透文字, 也不缩放或移动整组图形。完整股票走势图继续使用经典 `drawChipsCanvas`, 本次终端剖面只应用于快捷抽屉。
